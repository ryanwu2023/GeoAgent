# 俄罗斯金融压力监测

联合采集美元兑卢布、俄罗斯政策利率和 Brent 原油背景数据，用于观察油价、汇率与国内金融条件的共同变化。指标只提供压力线索，不自动推导制裁效果或资产方向。

本地自检：

```powershell
python russia_financial_pressure_monitor.py --self-test
```
