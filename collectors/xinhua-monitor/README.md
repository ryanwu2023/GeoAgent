# 新华网中文国际动态

运行 `python xinhua_monitor.py`，自检 `python xinhua_monitor.py --selftest`。

从新华中文国际即时新闻页解析官方“加载更多”JSON，筛选近七日美伊、地区冲突和俄乌标题，再读取正文；保留原文 HTML、列表 JSON、发布时间（北京时间）和采集时间（UTC）。这是一条中文补充通道，不保证覆盖新华网全部栏目。

`output/geo-v6.json` 供地缘政治智能体自动适配。累积保留历史数据；同题同日镜像合并并记录别名。`_collection_report.json` 记录自动发现、指定链接补采及失败；原文可访问不等于报道中声明已核验。

用户指定的样本报道既有根目录链接，也有国际频道镜像；报告分别记录自动发现镜像与直接抓取结果。
