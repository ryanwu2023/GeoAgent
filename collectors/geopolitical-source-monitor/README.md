# 多源地缘新闻监测

`geopolitical-source-monitor` 统一采集公开官方来源和国际媒体中与美伊局势、俄乌冲突相关的军事、外交、制裁、经济民生、人员伤亡、军费与援助资料。

本采集器不采集台海主题，不破解验证码，不绕过登录或付费墙，不使用代理池规避封禁。受限来源只保存匿名访问者可以看到的标题、摘要、发布时间和原始链接，并标记为“标题级线索”或“公开元数据”，不能视为已经核验的事实。

## 关键词口径

配置文件将关键词分为三层：

- **发现词：** 伊朗、革命卫队、霍尔木兹、胡塞、乌克兰、俄罗斯、顿巴斯等主体和地理锚点；同时包含英语、波斯语和俄语词形。
- **准入词：** 战争、打击、导弹、谈判、停火、制裁、军费、通胀、伤亡、能源设施、武器交付等事项词。
- **排除词：** 体育、娱乐、旅游、文化活动等明显主题污染。

普通记录必须同时命中主题锚点和事项准入词。只出现“美国”“俄罗斯”“以色列”等宽泛国家名称不得准入。命中次数只是过滤依据，不代表冲突概率、事件强度或独立证据数量。

完整词表、来源入口、允许域名和内容访问策略见 [`config.json`](config.json)。

## 访问与降级

- 优先使用站点公开栏目、RSS、站点地图或公开结构化数据。
- 遵守 `robots.txt`，按域名限速，并使用 ETag、Last-Modified 和运行缓存减少重复请求。
- 对 429、502、503 进行有限退避；401、403、验证码和登录墙不循环重试。
- HTTP 200 但返回登录页、挑战页或空正文时，不计作全文成功。
- Reuters、AP、NYT、WSJ、FT、AFP 等来源预留授权接口环境变量，但未配置授权时仍只使用公开页面。
- 配置仅保存环境变量名称，不保存 API Key。可选名称为 `REUTERS_CONNECT_API_KEY`、`AP_MEDIA_API_KEY`、`NYT_API_KEY`、`DOW_JONES_API_KEY`、`FT_CONTENT_API_KEY`、`AFP_CONTENT_API_KEY`。

当前版本尚未调用上述授权接口；环境变量只是后续合法授权接入的预留位。

## 输出

| 文件 | 内容 |
|---|---|
| `output/geo-v6.json` | 累积去重后的正式记录，供快照导入 |
| `output/_collection_report.json` | 候选、准入、排除、重复与错误统计 |
| `output/_source_status.json` | 逐来源成功、受限、无数据或失败状态 |
| `output/raw/<运行时间>/` | 允许保存的公开列表页和公开正文归档 |

同题同日的镜像或转载会合并为一个 `origin_id`，原链接保存在 `aliases`，涉及的来源保存在 `source_mentions`，不重复计算独立佐证。

## 运行

从仓库根目录执行自检：

```powershell
.venv\Scripts\python.exe collectors\geopolitical-source-monitor\geopolitical_source_monitor.py --selftest
```

直接运行采集器：

```powershell
.venv\Scripts\python.exe collectors\geopolitical-source-monitor\geopolitical_source_monitor.py
```

通过统一管线执行并在成功后导入 PostgreSQL 快照：

```powershell
.venv\Scripts\python.exe scripts\collect.py --id geopolitical-source-monitor --timeout 900
```

也可以从“采集管线监控”页面选择该采集器后立即执行。统一采集服务完成后会调用现有导入流程，将结构化记录写入 `GEO_DATABASE_URL` 指向的 PostgreSQL，并启动中文化任务。直接运行本目录的 `run.bat` 只生成采集输出，不单独负责快照导入。

## 状态含义

- `ok`：来源访问正常并形成至少一条准入记录。
- `no_data`：访问正常，但当前页面没有符合主题门控的记录。
- `restricted`：公开入口受限，只能降级或未取得元数据；不是正文采集成功。
- `failed`：请求、解析或来源结构异常，需要查看错误字段。
- `partial`：部分来源失败，其他来源仍产生可用输出。

“采集器退出码为零”“快照导入成功”“报道内容得到独立核验”是三个不同结论，不得合并表述。
