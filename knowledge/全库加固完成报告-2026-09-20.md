## ① 采集稳定性：222 → 11

### 根因：探活通过 ≠ 目标站可抓

上一次日志里 222 个失败中 **151 个是 `Tunnel connection failed`**。顺着查下去发现真正的原因是：

```
环境代理漂到  http://127.0.0.1:57444
它对两个最常用的通用探针都正常：
    http://www.gstatic.com/generate_204        → 204
    https://www.cloudflare.com/cdn-cgi/trace   → 200
但同一时刻真实目标是：
    Yahoo  chart API   → 403（返回 JS 反爬挑战页，不是 JSON）
    Google News RSS    → 超时
而同机的 7897 出口对这四个目标全通。
```

这类出口我把它叫**「半死出口」**：连得上、探得活，但被目标站风控。它的危害在于——
因为探活通过，failover 逻辑**根本不会触发**；整轮抓取静默拿回一堆 403/超时，
日志上只显示「源失败 / 无数据」，排查方向被彻底带到「源挂了」。

### 三层处置（已全库落地）

| 层 | 做法 |
|---|---|
| ① 通用探活 | 只保留「筛掉**死端口**」的职责（gstatic204 + cloudflare trace） |
| ② **真实目标深探** | 新增 `_proxy_deep_score()`：用**真的会给客户端发挑战页**的站（Yahoo chart + Google News RSS）当探针，给存活出口**排序**，深探通过的排前面 |
| ③ 抓取时轮换 | 403 与网络层异常立即 `demote` 当前出口并顺延下一个（`404/429/401` 不重试；`410/451` 是内容级，换出口也没用） |

轮换签名后来又扩了一轮（v3）：除 `Tunnel connection failed` 外，
`WinError 10060`（连接超时）、`10054`、`RemoteDisconnected`、`Connection reset`、`timed out`
同样高度指向「**这个出口**到目标站的链路被掐了」，换出口经常立刻成功。
另外 `HTTP 202`（欧洲议会 RSS、JNS 实测到）不是失败，是响应异步生成中 → **等 2 秒原地重试，不换出口**。

**启动打印也改了**：以前只打印环境变量里的那一个代理，现在打印**实际生效的出口池**——

```
实际出口代理: http://127.0.0.1:7897；备用 2 个（环境代理 http://127.0.0.1:57444 被判为半死出口，已按深探结果改选）
```

否则「为什么不用环境代理」这个问题每次都要重查一遍。

## ② 数据可信度：三处会静默骗人的 bug

| # | 问题 | 修法 | 兜底断言 |
|---|---|---|---|
| 1 | **波动率量级错**：`rollstd` 用**价格差值**而非**收益率**算 σ，Brent 年化波动率算出 **4,634%**（实际 46.4%） | 新增 `return_base` 收益率模式 | verify：年化波动率 ∈ [0.5%, 300%] |
| 2 | **民调百分比误提取**：`(\d{1,3})%` 读不出小数（53.5% 整条丢）；分支顺序错导致「涨 N 个百分点」被当成水平值；渲染 `41.0%` 被解析成 `0%` | 正则支持小数；`percentage points` 分支优先；`%g` 渲染与解析同口径；排除 turnout 投票率；子群标 scope | verify：数值范围校验；自检新增 53.5% / 变化量 / 子群 / 投票率 4 例 |
| 3 | **时间窗被绕过**：iran-escalation 累积档 3512 条中有 **107 条** `published` 仍是原始 RSS 串（如 `Fri, 03 Jul 26`），绕过时间窗流入报告 | `tools/fix_iran_dates.py` 备份后回填，复读 0 残留 | verify：值日期 ≤ 运行日 |

另外 verify 新增的通用校验：**单位必填**（当场抓出 usdcny 缺单位，已补 `CNY/USD`）、
百分比变动单位 ∈ {bp, pp}、百分比数值 ≤ 10000 量纲兜底、全报告无 NaN/None/纪元零值。

**还有一处渲染误导**：无数据的序列在 finance §2「滞后」列显示 `正常(阈None)`、在分桶表「状态」列显示 `正常`。
新增 `fetch_state_cell()` / `status_cell()` —— **无值一律显示「无数据」**，缺阈值时不印 `None`。

## ③ 多语种与事件核验

- **多语种术语中译表**：9 个项目注入 `glossary`（ru 114、uk、fr+it 61、fa 17、he 15、ar+he 30），
  报告按命中数列「原词 = 中译」，读俄语/法语/阿拉伯语标题时不用反复猜。
- **跨源印证标注**：≥2 个不同发布方报道，或 T1 原始出处 → **已印证**；单源非 T1 → **待证**。
- **声明 vs 实际行动分离**：LATEST 新增「事件核验」节，含印证状态、性质分布、旗标统计、术语对照；
  ukraine-aid / asset-transmission 的 flags 明确区分 `announced_only`（仅宣布）与 `confirmed_action`（已执行），
  援助场景区分「承诺 / 交付 / 延误 / 附带条件」四层，**不同口径禁止混加**。
