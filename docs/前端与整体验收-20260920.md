# 地缘政治智能体：前端与整体流程验收

## 结论

本轮完成真实浏览器渲染与操作验收，并修复发现的布局、交互和阅读问题。适合继续开展本地研究原型演示；这不代表数据事实或投资结论已经核验。

环境：本机 Edge 独立测试实例，连接 http://127.0.0.1:8000/；桌面 1440×1000、窄屏 390×844。内置浏览器控制连接失败，因此改用独立实例，没有操作用户浏览器会话。使用快照 a8206c6f873fecd723bd6176。

## 已执行的端到端流程

- 地图加载、图层筛选、无点位提示；实际点击莫斯科关联点，打开地点报道列表及右侧证据详情。
- 新闻详情展示发布时间、采集时间；缺失时间明确标识“时间未披露”。
- 搜索曼德海峡指标，验证全部船型曲线的近 60 期、全部历史、鼠标点选、左右方向键和指标来源。
- 搜索不存在的指标，显示明确空状态。
- 重点指标卡片打开解释与来源；资产表打开条件传导详情。
- 切换俄乌主题，确认显示欧洲成本与援助产业链等独立传导路径。
- 情景推演和数据源页面可进入、阅读。
- 空问题禁止提交；实际提交“原油指标变化及关联”，本地问答返回计算、条件分析和引用。
- 简报档案可选择、阅读；Markdown 导出响应成功，内容包含完整研究简报。
- 错误起止日期显示错误，清除筛选后恢复。
- 窄屏地图、资产、指标、问答、简报检查无页面级横向溢出。宽表在局部容器内滚动。

可复运行脚本：`python scripts/acceptance_browser.py`。脚本包含 10 组流程断言，全部通过，未捕获页面 JavaScript 异常。地图点选另行实际操作通过，控制台未捕获错误。

后端自动测试 34 项通过；TypeScript 检查及 Vite 生产构建通过。Python 依赖有弃用提示，本轮未升级依赖。

## 尚未纳入通过范围

- 大模型尚未配置，本轮验证的是本地检索和规则分析，未验证真实模型供应商的超时与返回质量。
- 外部新闻链接未逐条访问；机器翻译仍可能存在混合语言、译名不一致和语义偏差。
- 地图点位是报道关联地区，候选报道的地理及主题归类并未逐条人工确认。
- 简报若有引用未列入原有索引，继续保留原始 ID，避免虚构来源链接。
- 未进行 Safari、Firefox、真实手机触摸设备、长时间压力、断网演练和全面无障碍审计。
- 本轮未触发重新爬取或数据导入，避免把视觉验收与数据刷新混在一起；未修改历史快照。问答操作会留下真实本地问答档案。
