# 地缘政治智能体产品设计文档 V6

版本：2026-09-18；适用：比赛本地演示与研究工作台首版。

## 一、产品定位

面向研究员和基金经理的“地缘指标变化驱动的大类资产研究助手”。美伊局势与俄乌冲突为两个并列主案例，按照《地缘政治跟踪框架-20260907.xlsx》组织资料。核心链路：

**采集 → 指标变化 → 证据核验 → 局势与情景 → 宏观传导 → 大类资产关联 → 简报与问答。**

研究员需要知道发生了什么、与什么基准比较、证据是否可靠，以及判断为何改变。基金经理需要快速理解变化的资产含义、条件与期限、反证，以及什么时候需要重新评估。两类用户共享数据底座，使用摘要和详情满足不同阅读深度。

首版不承担自动交易、收益预测、事件概率估计或组合权重优化。其价值取决于来源覆盖、时间口径和研究规则的质量，不能用更多报道替代更可靠的证据。

指标分为定量、定性和代理三类。定量指标定义单位、范围、更新频率、比较规则和解释边界；只比较同口径序列。定性指标优先采用状态及其变化，例如提出条件、启动会谈、达成协议、执行验证。代理指标单列，不倒推出不可观测的弹药库存。

每次更新应回答：变化是什么、比较基准是什么、支持与反向证据是什么、是否改变局势判断、通过何种机制影响资产、下一步观察什么。

## 三、数据接入与历史

独立爬虫逐个建设是可行的，但采集器和指标必须解耦。一个爬虫可支撑多个指标，一个指标可引用多个独立来源。新增爬虫增加字段映射、来源配置与指标绑定，不新增一套业务页面。

优先读取结构化 JSON/JSONL，Markdown 日报用于阅读和交叉核对。现有三个适配器只读原始项目，不执行或修改爬虫。新增项目可在 `output/geo-v6.json` 输出统一协议，详见 [接入协议](adapter-contract.md)。

|对象|关键字段|
|---|---|
|数据源|稳定 ID、发布主体、类型、采集状态、状态时间|
|原始记录|稳定 ID、来源链接、片段、发布时间、采集时间、原始文件引用|
|指标定义|主题、维度、名称、单位、频率、范围、方法与边界|
|指标观测|观测日期、值或缺失、来源 ID、所属快照|
|事件/声明|主体、说法、时间地点、信息性质、核验状态|
|情景/资产分析|条件、机制、方向、期限、引用、反证、触发项、版本|
|简报/问答|使用的快照、筛选范围、生成时间、模式、引用及正文|

发布时间、事件时间、采集时间、首次发现分别保存，未知保留空值，不用导入时间冒充采集时间。原始文件按内容哈希归档，SQLite 保存不可变快照、记录版本、分析、问答和简报。

重复导入相同输入复用快照；数据修订产生新版本，旧版本仍可回放。新增、修订和当前范围记录分开统计。页面、问答、引用与简报均绑定快照 ID。历史回放仅反映当时实际冻结的数据；当前抓到的旧文章不能自动还原过去的信息集。

相同规范化 URL 归并，保留原始档案引用。明确提供原始出处的转载在检索和候选证据中按同一出处处理；未知转载关系不自动声称已识别。来源状态区分正常、无新增、失败、未接入、停用及采集状态未知。

## 四、证据与分析

数值计算由程序完成，大模型负责有条件的解释。展示当前值、前值、变化额、变化幅度和历史趋势；缺失不填零，零基数不计算百分比。历史不足不生成分位数或统计异常结论。

来源等级、信息性质、核验状态分别管理。官方通报证明“该方作出通报”，不自动证明内容。同期提及一个议题仅是比较线索。地点提及、母港、近似海域和明确位置记载分开；离散报道不得连接成真实轨迹。美国整体军费是背景指标，不能直接归因于某一冲突。

两个主题分别采用持续消耗、升级扩散、缓和收束三个情景。情景记录成立条件、驱动、支持与反证、相较前次变化、失效条件、后续观察项和数据缺口。首版不由关键词分数生成风险分或事件概率。

|宏观渠道|需核验的中间变量|
|---|---|
|供需与运输|能源、粮食、航道、设施、出口、替代供给|
|通胀与政策|冲击持续性、通胀预期、货币政策预期|
|增长与贸易|生产、需求、限制、运输成本、援助|
|风险偏好与流动性|外溢、尾部风险、谈判可信度、资本流动|
|财政与产业需求|军费、补库、援助、财政压力、订单|

传导规则是可审阅、可修订的研究假设，保存规则版本。五类资产为权益、利率债、信用债、商品和外汇。后续按地区、行业、原油/天然气/黄金及具体货币展开。

每项资产输出：主题、新增驱动、判断变化、条件方向、传导机制、期限、引用、反证、市场验证及下一触发条件。方向标签为偏正面、偏负面、双向作用、证据不足。默认无足够依据则保留证据不足；模型输出均标记待研究员核验。双主题影响不可简单相加，同一证据不可重复当作独立支持。

经济传导假设、市场实际表现、统计关联分别呈现。价格同步变化不能证明因果。市场数据接入后，应比较事件窗口、市场预期、替代解释和反向证据，再研究规则效果。

## 五、问答与简报

问答覆盖当前已接入资料，可按主题、维度、发布时间和快照筛选。数字查询调用结构化计算；来源问题检索原文；综合问题结合证据和研究规则；跨主题问题检索双方并识别共同或相反作用。

回答显示数据截至时间、生成模式和可打开的引用，区分程序计算、原始材料和模型推论。采集文字是不可信资料，不是模型指令。模型解释校验引用 ID，禁止输出未经程序计算的新数值；这种校验不等于语义核验。没有足够依据时明确说明。

未配置模型时使用本地关键词检索、数值计算及证据简报。模型超时、接口失败或输出不合格时保留本地证据。历史问答明确显示回放。问题中的“本周”在没有手动日期范围时，以冻结快照导入日期所在周为基准。

简报包括双主题重要变化、计算结果、情景与反证、分别列示的大类资产矩阵、观察项、缺口、引用和规则版本。支持网页阅读、Markdown 导出和版本差异比较；生成模式不伪装。全量双主题简报使用当前完整快照，不继承页面局部日期筛选。

## 六、页面与地图

以用户 V5 HTML 的工作台布局为依据：顶部主题切换，中央功能页签与地图，右侧常驻研判栏。大屏固定首屏高度，中央和右侧分别滚动。窄屏改为上下排列。

中央页签：风险监测、证据台账、情景推演、数据源、智能问答、量化指标、资产关联、研究简报。顶部提供快照选择、更新快照和生成简报。综合研判默认进入资产矩阵。

地图采用 MapLibre GL + deck.gl 二维实现，本地 Natural Earth 地理边界、暗色海陆底图、国界和中文标签，无外部瓦片或字体服务依赖。借鉴 World Monitor 的暗色图层与详情联动方向，没有复制其应用源码。

支持全球/主题聚焦、缩放拖动、日期与维度筛选、位置证据图层开关、聚合点位及同一地点的记录列表。选中点位在右侧展示原文、来源、时间、核验状态和快照档案。明确位置、近似位置、文章提及采用不同颜色；当前爬虫地点字典结果只标为文章提及。

地图不是所有指标的主视图。财政以趋势、声明以证据详情、外交以情景条件表达，不能强行地图化。地图可离线显示，外部原始来源链接仍需网络。没有位置证据时明确提示，不补造热点或模拟轨迹。

### 中文与综合态势修订（2026-09-18）

根据用户反馈，中文成为默认阅读语言，包括新闻标题、摘要、来源、地点、问答引用和简报。英文原始链接保持不变，原文与译文分别存储。译文使用本地模型缓存，并支持编辑修订与爬虫直接提供中文字段。尚未准备完成的译文明确提示，不以编造内容替代。

地图从单一位置精度图层调整为六类事件：军事行动、外交谈判、制裁与政策、能源与运输、军费与援助、政治与社会。跨来源报道可按地名匹配到地区参考点；精度和依据保留在详情，不把新闻参考点表述成精确部署。

悬浮提示简化为“地区 · 若干条相关动态”和涉及的事件类型、态势线索，移除重复的操作说明。提供升级相关、持续相关、缓和相关、待研判筛选。线索分类依据报道标题或适配器显式证据，不把单条新闻或报道数量直接当作整体冲突结论。

## 七、技术结构

- 前端：React、TypeScript、Vite，MapLibre GL 与 deck.gl。
- 后端：Python、FastAPI。
- 存储：SQLite 和内容寻址原始文件档案。
- 模型：后端配置兼容 Chat Completions 的接口；凭据只在后端环境读取。
- 部署：比赛电脑本地 `127.0.0.1:8000`；前端构建由 FastAPI 服务。

单一分析流程为范围锁定、检索、程序计算、证据整理、情景解释、资产映射与引用检查，暂不引入复杂多智能体编排。

API 按快照、工作台、证据、档案、问答、简报、简报差异划分。模型资产与情景结果按快照、主题、维度、日期范围和规则版本隔离，不能串入其他主题页面。详细运行方式见 [README](../README.md)。

## 九、验收与比赛演示

验收关注重复导入不重复计数、修订可回溯、单位和范围可核对、缺失不当零、同源不重复计证、单方声明不当事实、地图不伪装实时部署、所有输出快照一致、问答引用存在、失败仍保留证据、新适配器无需重写页面。

演示路径：**双主题变化 → 各选一条证据链 → 情景条件与反证 → 五类资产矩阵 → 现场追问 → 生成与导出简报。**

真实采集、现场模型、本地检索、历史回放和未接入能力必须明确区分。无模型凭据时只能验收本地流程及模拟模型接口测试，不能宣称真实模型效果已验证；没有俄乌完整专题和市场数据时不能宣称完整研究覆盖。
