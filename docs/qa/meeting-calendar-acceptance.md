# 会晤日历整合验收记录

验收日期：2026-10-25

## 交付范围

- `meeting-calendar-monitor` 已作为第 27 个原生采集器进入统一注册表和每日管线。
- 采集器输出保留会晤 ID、日期精度、地点、人物、状态、冲突、来源、声明和状态变化。
- 冻结快照新增 `meetings`，并为问答、简报和证据核验生成标准证据记录。
- 前端增加“会晤日历”，支持主题、人物、状态、有效/非有效日程筛选和详情核验。
- 风险地图增加独立紫色“计划会晤地点”图层；计划地点不进入普通新闻/军事点位。
- 研究简报的情景部分自动列出当前快照中的近期有效会晤及引用 ID。

## 边界检查

- 月份、当周、日期区间和待定日期保留原精度，不补造具体日期。
- 取消、推迟、否认、过期未证实和已举行默认不进入未来有效日程，可由用户显式打开。
- 选举等政治基线标记为“非会晤”，不作为领导人会晤显示或上图。
- 国家、地区或未知地点不生成精确地图点；仅受控地点字典中的明确城市上图。
- 地图会晤点固定提示“计划会晤地点，不代表实时位置”。
- 会晤标准证据的普通地图点为空，展示层也禁止根据标题重新推断地点。
