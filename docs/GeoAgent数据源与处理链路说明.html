01 / 整体概述

持续跟踪美伊局势与俄乌冲突，把分散资料组织成可查询、可追溯的研究底座

GeoAgent 从新闻、官方数据、市场数据和补充资料中持续采集两大主题的动态，经过相关性筛选、主题分类、去重、中文化与证据标记后，统一进入风险监测、量化指标、情景与资产分析、智能问答和简报生成。

动态资讯采集

固定抓取美伊、俄乌相关的军事行动、外交进展、政策变化、能源与运输、援助及内部政治信息，并保留原文链接、发布时间和采集时间。

分类与风险展示

按主题、维度、事件类别和地点组织新闻，自动形成升级、持续、缓和或待研判线索，同时允许用户复核和调整。

定量数据监测

采集市场价格、利率、通胀、能源库存、航运、财政、援助和其他可量化指标，展示历史走势、变化幅度、单位、口径与来源。

情景与资产关联

结合新闻变化和量化指标，整理基准情景、尾部风险、触发条件、反证以及原油、黄金、利率债、信用、权益和外汇的传导逻辑。

智能问答

用户可直接询问近期进展、主要变化、判断依据、反向证据和资产影响；模型根据原始问题与当前快照中的检索证据生成中文回答。

简报与报告生成

从同一数据快照生成美伊与俄乌简报，包含核心判断、主要事项、后续走势、资产含义和引用；后续将进一步结合业务理解生成专题报告。

02 / 适用用户

同一套证据底座，支持不同深度的研究与决策

系统不代替用户做最终判断。它减少重复检索和资料整理，把结论、反证、数据缺口和后续触发条件放在同一页面，方便研究讨论和投资决策复核。

研究员如何使用

围绕具体主题建立持续更新的研究台账，从新变化回到原始材料，再形成可引用的观点。

  • 筛选重要动态，比较不同来源和当事方说法
  • 查看新闻发布时间、采集时间、来源等级和核验状态
  • 把定性事件与量化指标放在同一时间线上
  • 确认或调整升级、持续、缓和和待研判分类
  • 生成简报并保留版本，复盘结论为何改变

基金经理如何使用

从当前局势直接进入资产含义，快速识别需要关注的风险渠道和重新评估条件。

  • 先读双主题概况、核心变化和一句话判断
  • 查看原油、黄金、美债、信用、权益和外汇的条件影响
  • 理解事件如何通过供需、通胀、增长和风险偏好传导
  • 同时查看反证、数据缺口和下一观察项
  • 通过问答追问某项判断的依据和不确定性

04 / 典型使用流程

从一个研究问题出发，而不是从阅读全部新闻开始

用户可以先查看系统筛选出的变化，再逐层深入证据和资产传导。任何阶段都能回到原始来源，检查系统为何得出当前结果。

01

选择主题

进入美伊或俄乌工作台，设置时间和研究维度。

02

发现变化

查看风险地图、重点动态和变化明显的量化指标。

03

核查证据

打开新闻详情，检查原文、来源、发布时间和核验状态。

04

形成判断

比较支持证据与反证，确认分类并查看情景成立条件。

05

理解资产

沿供需、通胀、增长、流动性和财政渠道查看资产影响。

06

问答与输出

追问判断依据，生成简报并保留引用和版本。

05 / 可以获得什么

页面输出围绕“结论能否被理解、追问和复核”组织

同一冻结快照供风险监测、指标、情景、资产、问答和简报共同使用，避免不同页面引用不同批次的数据。

每日研究简报

面向晨会、主题跟踪和投资讨论的可阅读结果。

  • 二至三句话的核心判断
  • 按当事方或地区整理的主要事项
  • 基准情景、尾部风险、触发条件和反证
  • 大类资产影响及传导逻辑
  • 可打开的证据与信源

大类资产影响矩阵

把地缘事件与资产之间的中间传导环节写清楚。

  • 新增驱动与判断变化
  • 条件方向和影响期限
  • 供需、通胀、增长、风险偏好与财政渠道
  • 市场验证、反证和失效条件
  • 下一次需要重新评估的触发点

有引用的智能回答

直接回答局势进展、主要变化、判断和不确定性。

  • 使用用户原始问题，而不是固定检索模板
  • 结合新闻证据和结构化指标
  • 数字来自程序查询和计算
  • 引用可以返回原始记录和外部链接
  • 模型失败时仍保留本地证据结果

可复核的数据台账

为后续研究复盘保留当时使用的数据和判断过程。

  • 不可变快照和原始文件归档
  • 新闻与量化观测分开保存
  • 用户复核记录和简报版本
  • 来源健康、采集日志与数据缺口
  • 翻译缓存不修改原始证据
06 / 能力边界与反馈

系统提供研究辅助，最终判断仍需要用户确认

页面把证据、推论和不确定性同时展示。试用阶段最有价值的反馈，是指出哪些信息真正改变判断、哪些指标没有决策意义，以及什么条件会促使用户重新评估资产。

当前边界

  • 关键词命中只代表候选线索，不证明事件真实发生。
  • 来源等级反映来源类型，不等于每项陈述已经核验。
  • 机器译文可能存在专名和语义偏差，原始链接始终保留。
  • 情景是研究假设，不输出缺乏依据的事件概率。
  • 资产方向是条件判断，不提供价格目标、收益预测或交易指令。
  • 部分官方接口需要密钥，缺失时明确显示配置或数据缺口。

希望研究员和基金经理重点反馈

  • 当前十三类研究维度是否覆盖实际跟踪框架？
  • 哪些新闻分类、来源等级或态势标签需要调整？
  • 哪些量化指标能够改变判断，哪些指标应删除或替换？
  • 情景的触发条件、反证和观察项是否足够具体？
  • 资产传导链是否符合实际决策过程，缺少哪些市场数据？
  • 简报是否适合晨会和投资讨论，还需要哪些格式与长度？

03

统一适配

旧 JSONL 与 geo.v6 输出统一成新闻记录和量化观测两类对象。

04

平台清洗

规范链接、去重合并、时间隔离、主题污染清理、字段校验和原始归档。

05

标签与使用

生成主题、维度、事件类别、态势线索、地点精度与翻译状态，再进入各功能页面。

展示当前启用爬虫实际提交的搜索词

10 / 清洗过程

原始材料保留，分析资格可以被移除

清洗不会删除证据原文。记录若与主题无关，会移除主题和维度标签并改为背景资料，同时保留排除原因；这样既避免污染分析，也能解释某条材料为什么没有进入主题页面。

原始文件归档

每个读取文件计算内容哈希并复制到 archive，快照记录文件名、哈希和归档名。

链接规范化

仅接受 HTTP/HTTPS；删除片段、跟踪参数和可能包含密钥的查询参数。

稳定 ID 与去重

按规范链接或来源 ID、标题、发布时间生成稳定 ID；重复项合并来源适配器、原始引用、主题候选和更完整正文。

时间质量

区分事件、发布、采集和首次发现时间。发布时间晚于导入时间两天以上时隔离该时间，不参与时效排序。

主题污染清理

体育、公共卫生、自然灾害、文化旅游，以及与俄乌无直接关系的一般贸易会被移出主题；若标题含明确安全行动词则保留。

主题与维度校验

美伊八类、俄乌五类维度均需在目录内；geo.v6 显式绑定若使用未知主题或维度，整条输入拒绝。

量化指标校验

单位、频率、范围、方法、边界和来源引用必填；日期不可重复，数值只能是有限数或空值，缺失不填零。

地点质量

坐标必须标注 explicit、area 或 mention，并携带证据文字；文章地名不能表示实时部署。

中文化与缓存

中文原文直接使用；其他语言写入持久翻译缓存，并检查数字保持、残留外文和术语一致性。原文始终不变。

12 / 标签体系

是的，新闻与结构化数据均有标记，而且标记分层

不能把自动标签和人工确认混为一谈。平台保留上游标签，生成用于展示的派生标签，并允许用户对态势线索做版本化复核。

来源自带标签

topics / dimensions：采集器显式绑定的主题和维度。
crawler_buckets / flags / stance：上游命中的词桶、实体、立场和信号。
tier：T1官方、T2专业媒体、T3聚合或一般来源、未分级。

平台派生标签

classification / scope：显式绑定、关键词候选、背景资料或清洗排除。
event_category：军事、外交、政策、能源、援助、内政。
situation_signal：升级、持续、缓和、待研判。

用户复核标签

review.signal：用户确认或调整后的态势分类。
review.reason / version / created_at：理由、版本和时间。
复核后仍保留 automatic_signal，便于比较自动判断与用户判断。

核验与性质

nature：官方通报、媒体报道、结构化指标、补充资料等。
verification：待核验、原文已采集、官方数据已导入等。
“官方发布”只证明发布行为，不自动证明内容。

位置标签

precision：explicit 明确位置、area 区域参考、mention 文章提及。
evidence_text / role：原文地点依据与地图解释。
没有证据文字的坐标不能进入 geo.v6。

翻译与质量标签

translation_quality：中文原文、机器译文待语义核验或待复核。
issues：数字变化、外文残留、术语问题。
译文进入缓存，原始标题和正文保持不可变。
