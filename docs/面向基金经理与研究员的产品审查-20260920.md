# 面向基金经理与研究员的产品审查

审查日期：2026-09-20。检查范围：当前后端、前端、快照、检索与分析逻辑，以及正在运行的模型配置。此次为产品与实现审查，没有修改业务代码，没有重新逐条核实新闻，也没有进行完整浏览器交互回归。

## 一、总体判断

当前产品已经具备资料接入、指标查看、来源追溯和研究材料检索的基础，适合作为研究员的资料工作台。距离基金经理日常使用的决策支持工具，还缺少四个关键环节：重要变化排序、可修订的研究观点、具体资产暴露、观点失效提醒。

建议以“今日哪些变化值得关注、为什么影响我关注的资产、哪些证据会使判断改变”为主线。地图承担事件定位和证据探索；基金经理首页优先展示变化与影响。

当前快照 `a8206c6f873fecd723bd6176`：17个输出项目，9,931条来源记录，68个指标定义，另有7个补充报告章节包含在记录中。指标定义数量不等于全部有有效值。当前模型接口未配置，现场能力为检索、程序计算与规则研判。

来源状态共有513个配置条目：366个正常、72个已导入但采集状态未知、54个停用、5个正常但不在窗口内、12个失败、3个无数据、1个正常无新增。它们不是独立网站数量。旧报告的222个失败属于旧快照，不能沿用为当前状态。

## 三、基金经理的理想首页

建议一屏回答以下问题，每项可展开证据：

1. **今日最重要的3—5项变化**：相对何时、变化幅度、是否持续、可靠度以及为何与关注资产相关。
2. **需要重新评估的资产**：明确地区、行业、币种或久期；显示作用条件和观察期限。
3. **观点变化**：维持、加强、减弱或撤回；附新增证据及最强反证。
4. **后续触发条件**：例如经核验的供应损失持续、交付中断或协议执行，而不是只设置新闻篇数阈值。
5. **数据盲区**：关键源停更、数据过期、译文待核验或存在相互冲突的材料。

不要用单一“综合风险分”取代这些信息。若以后使用评分，先明确它衡量的是关注优先级、证据可靠度还是经济影响，不能混在一起。

## 四、研究员的工作流程

推荐流程：新增资料收件箱 → 归入事件 → 比较声明与实际行动 → 核验及备注 → 修改主题观点 → 更新条件资产影响 → 发布简报 → 追踪反证。

研究员需要的操作包括：保存搜索、收藏指标、比较不同来源的同一主张、合并转载、标注译文问题、确认单位口径、编辑传导假设、记录结论与审核人。当前主要是查看和生成，尚缺“处理后留下可复用研究成果”的环节。

同一证据应只维护一份。研究员看到原句、计算和争议；基金经理看到结论摘要和关键触发条件，二者使用同一观点版本。

## 五、情景与资产分析的具体升级

情景应成为有条件的研究对象，而不只是三个说明卡片。每种情景维护关键假设、所需观测、当前支持、当前反证、待核验项和失效条件。先由研究员确认状态，暂不输出未经校准的发生概率。

资产分析建议每条记录采用：

> 主题及事件 → 新增事实/声明 → 传导渠道 → 受影响资产与暴露 → 条件方向 → 时间范围 → 市场观察 → 反证 → 下一触发点。

经济机制、市场实际表现、统计关联三个字段分开。美伊和俄乌若影响同一能源渠道，应在资产层说明共同与相反作用，不能叠加报道数量当作冲击强度。

可先支持自选研究篮子，如中国权益、港股、人民币利率债、黄金、原油及外汇。具体默认篮子需要基金经理确认；若以后接持仓，先只计算暴露和提示，避免把数据不足的判断变成自动交易建议。

## 六、补数据的顺序

| 顺序 | 应补内容 | 解决的问题 |
|---|---|---|
| 1 | 供应设施损失、停产持续时间、实际出口、替代供给 | 新闻威胁是否变成经济数量变化 |
| 2 | 运费、战争险、交付延迟、航程与船型覆盖 | 通行变化如何影响成本与供给，而非只看艘次 |
| 3 | 援助承诺、批准、拨款、交付的分阶段记录 | 支持能力是否真正变化 |
| 4 | 停火协议文本、执行、违反事件、第三方核查 | 外交表态是否转化为持续缓和 |
| 5 | 欧洲天然气与储气、粮食贸易；中国与欧洲资产基准 | 降低美国市场样本偏差，改善俄乌与国内配置研究 |
| 6 | 同机构同问题的民调、完整问卷与样本 | 支持可比较的政治约束趋势 |

已经有新闻爬虫的领域，优先增加数量、实际执行和来源口径，而不是再接一个重复转载源。

## 七、推荐实施顺序与验收

### 第一批：可靠的研究简报

修正指标重要性选取、主题资产分析、数据时效和语言路由；把背景报告分层。验收：对同一快照，两主题有各自依据；不同期限数据明确标注；没有新增证据时不制造新观点；补充报告不升级为已验证事实。

### 第二批：研究工作流

实现事件台账、原文引用定位、核验操作、观点版本和反证清单。验收：任何已发布观点都能找到责任人、使用快照、支持证据和撤回条件；修改观点可以解释原因。

### 第三批：基金经理入口

增加自选资产、重要变化摘要、关注条件和变更提醒。验收：用户能在短时间内回答“今天需要重新看什么、为什么、下一步等什么证据”；重复报道不重复提醒，停更只产生数据质量提醒。

### 第四批：研究验证

建立历史事件样本、时间对齐、对照资产及假设复盘；检验不同触发条件是否有研究价值。不能用一次价格同步变化证明传导规则有效，也不能把回测收益当成首版可信度替代品。

## 八、如何判断是否真的对用户有用

建议让2—3名研究员和1—2名基金经理用真实任务试用，以下为建议验收项目，不是已测得指标：

- 找到本期最重要变化及最强反证，记录耗时及遗漏。
- 从资产判断返回支持原句，检查引用是否实质支持结论。
- 识别过期、误译、转载及口径不同的资料，记录误判。
- 连续观察同一主题，确认观点变化与新增证据一致。
- 用未覆盖问题测试拒答和缺口提示，避免用常识补造事实。
- 按“能否减少研究时间、是否发现遗漏、是否改变观察清单”评价，而不仅是回答流畅度或新闻数量。

本次建议的首要交付是“有主题差异、可追溯、能说明变化原因的研究简报”，随后才是更复杂的情景概率、组合模型和多智能体编排。
