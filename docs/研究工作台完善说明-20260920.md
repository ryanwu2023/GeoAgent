# 研究工作台本轮完善

面向基金经理快速理解资产渠道、研究员回查条件和证据，规则版本更新为 v6.3。

## 已实现

- 美伊与俄乌分别提供权益、利率债、信用债、商品、外汇的条件传导、反证、下一观察项。
- 条件路径只附最近十四天、当前主题与筛选范围内的新闻候选；补充研究报告不计作独立事实支持。
- 资产页展示七项重点指标，按主题优先级与渠道选取，同类最多两项。问答和简报采用相同选择规则，不再默认取前七项财政数据。
- 指标区分可用、滞后、缺失、日期待核对和隔离。默认按日频七天、周频十四天、月频四十五天判断；有来源容忍期时优先使用。此为日历日运营规则，不是统计异常阈值。
- 滞后指标保留查阅，不用于当前市场方向描述；页面、问答、简报展示缺口。
- 选择军事等研究维度时，资产研究保留共享市场背景，同时新闻证据仍遵守维度筛选。
- 简报概述根据当前可用市场观测组织，矩阵分别展示两主题的传导条件。最新本地规则简报已保存到简报档案并导出同目录。

## 验证

34 项自动测试通过；TypeScript 与生产构建通过。运行中的两主题接口各返回七项重点指标，且主题传导路径不同；首页响应正常，双主题简报生成成功。浏览器控制连接失败，本轮未完成视觉验收。

## 保留的研究边界

条件路径是可审阅的研究规则，新闻匹配仍是关键词候选，不能证明条件已经发生。未生成概率、价格目标或收益预测。当前未配置大模型接口，使用本地检索与规则研判。

后续重点是研究员逐条核验与观点修订记录、事件前后市场验证、欧洲及中国资产覆盖、跨语种翻译质量，以及按发布时间与修订版本进行历史回放。当前时效检查按快照或用户筛选截止日判断，不等于历史无前视回测。
