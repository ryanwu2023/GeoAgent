# 会晤日历双视图设计

## 目标

把现有的会晤台账升级为“月历总览 + 日程详情”双视图，让用户先按日期发现事件，再在同一页面核对事件、人物与职务、地点、时间、状态和来源。

## 交互与信息结构

- 保留现有标题、统计卡和状态/人物筛选；筛选同时作用于月历和日程卡片。
- 月历以周一为一周起点，固定显示六周。支持上月、回到数据基准月、下月。
- 日期格展示当天事件简称和状态色；超过三条时显示“另有 N 项”。点击日期只看当日日程，点击已选日期可取消；点击事件定位并强调对应详情卡片。
- 日程卡片完整显示日期或日期范围、事件、相关人物及职务、地点、状态、事件类型和信源数量；展开详情后提供原始来源及关联证据入口。
- 无精确日期的记录不硬塞进月历，仍保留在下方“日期待定”台账中。

## 视觉与响应式

- 沿用项目深蓝底色和青色主强调，不使用渐变。
- 已确认使用绿色、已安排使用青色、预告/待确认使用琥珀色、取消/否认使用低饱和红灰色。
- 桌面端完整展示七列月历；窄屏保留最小宽度并允许月历区域横向滚动，详情卡片改为纵向排列。
- 所有交互元素使用按钮语义、可见焦点和 aria 标签。

## 验收

- 月历能正确处理月首偏移、跨月日期、日期范围和同日多事件。
- 选择日期后，详情列表与月历状态同步。
- 用户无需打开抽屉即可看到事件、人物、地点和时间四项核心信息。
- `npm test` 与 `npm run build` 通过，并在运行页面完成桌面与窄屏视觉检查。
