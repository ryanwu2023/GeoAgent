# 智能问答 HTML 报告导出设计

## 目标

在 GeoAgent 智能问答的每条最终回答下增加“保存 HTML 报告”操作。系统直接使用该回答已经完成引用与数字校验的内容生成独立中文网页，用户可下载并离线打开。导出过程不再次调用模型，确保网页内容与屏幕答案一致，并避免额外等待和二次生成偏差。

## 已选方案

采用后端确定性导出：前端只提交回答 ID，后端从答案库读取回答及其冻结证据，生成 HTML 并以附件形式返回。

未采用的方案：

- 前端拼装 HTML：实现较快，但难以统一转义、下载命名、证据格式和安全策略。
- 保存时再次调用模型生成报告：版式更自由，但速度慢，且可能产生新的数字、引用或结论偏差。

## 用户流程

1. 用户完成一次智能问答。
2. 最终回答下方显示“保存 HTML 报告”。分析尚未完成时不显示该操作。
3. 用户点击后，前端请求该回答对应的导出接口。
4. 后端验证回答存在，生成 UTF-8 HTML，并返回附件。
5. 浏览器下载文件；前端显示成功或失败提示。

## 报告内容

- 报告标题：由用户原始问题生成安全、简洁的文件标题。
- 元信息：主题范围、数据截至时间、报告生成时间和回答模式。
- 总结正文：保留当前回答的 Markdown 层级、列表、加粗和表格等常用格式。
- 关键证据：只展示回答实际引用的证据，包含来源媒体、发布时间、采集时间、证据标题或内容要点、来源等级、核验状态和原始链接。
- 口径与限制：展示回答中的数据缺口与校验降级说明。
- 分析过程不进入报告正文；内部回答 ID、证据 ID、快照 ID 和模型配置不对外展示。

## 后端设计

新增只读下载接口：

`GET /api/answers/{answer_id}/report.html`

接口从现有答案表读取保存后的完整回答。HTML 生成器作为独立模块，负责：

- 对所有用户问题、模型正文和证据字段做 HTML 转义；
- 将受限 Markdown 转换为安全 HTML，不执行原始 HTML、脚本或事件属性；
- 只使用答案自身 `summary.evidence_ids` 对应的冻结引用；
- 生成不包含内部标识的证据表；
- 设置 `Content-Disposition: attachment`、UTF-8 内容类型和限制主动内容的安全响应头；
- 对不存在的回答返回 404，对缺少总结的回答返回明确的 409。

## 前端设计

在最终回答操作区增加“保存 HTML 报告”按钮。点击后使用原生下载请求获取 Blob，并从响应头或用户问题生成文件名。下载期间显示“正在生成”，失败时保留当前回答并显示提示。按钮不触发新的模型请求。

## 安全与证据边界

- 报告只导出已保存并完成问答校验的回答，不接受前端提交任意 HTML。
- 外部链接仅允许 HTTP/HTTPS，并增加 `rel="noreferrer noopener"`。
- 证据中的原始文本只按纯文本展示，避免采集内容成为网页指令。
- 若回答处于校验降级状态，报告照常生成，并保留相应限制说明。

## 测试与验收

- 正常回答可下载 HTML，中文文件名和 UTF-8 内容可正常打开。
- 报告包含问题、总结、来源、发布时间、采集时间、证据要点和原始链接。
- 报告不包含快照 ID、回答 ID、证据 ID、API 地址、密钥或模型配置。
- Markdown 标题、列表、加粗和表格正确显示；输入中的 HTML 与脚本被转义或移除。
- 引用越界、没有总结、回答不存在和下载失败都有明确处理。
- 导出不调用大模型，报告正文与当前回答一致。
