# 多源地缘新闻采集器设计

## 1. 建设目标

新增一个配置化采集器 `geopolitical-source-monitor`，统一采集美国、伊朗、中国、俄罗斯和欧盟官方来源，以及主要国际媒体中与美伊冲突、俄乌战争相关的公开信息。

采集器向现有 GeoAgent 数据链路输出 `geo.v6/1` 数据，进入已有的快照、证据台账、智能问答和研究简报。此次不新增台海主题，也不采集台海候选资料。

本设计不包含验证码破解、代理池规避封禁、伪造登录、绕过付费墙或访问非公开接口。受限来源只保存匿名用户可以访问的标题、摘要、发布时间和原始链接。

## 2. 方案选择

采用单一采集器、站点适配器分离、配置驱动的方案。

- 对外只有一个采集器 ID，便于在采集管线页面统一启停、重试和查看状态。
- 内部每个站点使用独立适配器，一个来源失败不影响其他来源。
- 来源 URL、抓取方式、语言、等级、限速和栏目均放在配置文件中。
- 主题锚点、事项词、排除词与维度映射集中配置，后续调整关键词无须复制采集代码。
- 官方接口、RSS 或站点地图优先；其次使用公开栏目页；受限媒体降级为公开元数据。

不采用把来源分别塞入已有美伊、俄乌采集器的方案，避免同一网站重复请求和重复记录；也不拆成官方与媒体两个采集器，避免增加调度和运维入口。

### 4.4 准入逻辑

普通新闻至少满足：

1. 标题命中一个主题强锚点；或标题与摘要共同命中主题主体和地理关系；
2. 标题、摘要或正文命中至少一个事项准入词；
3. 未命中明显无关排除规则。

官方专题页面允许采用更窄的来源先验，例如 CENTCOM 的伊朗、胡塞、红海、波斯湾报道仍需命中具体主体或行动词，不能把该站全部新闻直接归入美伊。

只出现“美国”“中国”“俄罗斯”“以色列”等宽泛国家词时不得准入。

### 4.5 排除与降级

- 体育、娱乐、旅游、文化展览和一般人物生活资讯直接排除。
- 同名人物、球队或地名未涉及冲突事项时排除。
- 俄罗斯、伊朗的一般贸易或企业新闻，未涉及战争、制裁、财政、能源或民生传导时排除。
- 评论、专栏和历史回顾可保留为“研究观点”，不得作为独立事件确认。
- 只有标题、没有摘要或正文的记录标记为“标题级线索”。
- 重复转载归并到同一 `origin_id`，记录别名和发现来源，不增加独立佐证数。

## 5. 主题与维度映射

### 5.1 美伊

- 美军部署、五角大楼、CENTCOM、基地与补给：`us_readiness`
- 革命卫队、伊朗军演、导弹与无人机：`iran_readiness`

- 伊朗通胀、汇率、就业、短缺与国内政治：`iran_domestic`
- 以色列相关军事与政治行动：`israel`

- 谈判、斡旋、停火与协议执行：`diplomacy`

## 6. 组件设计

### 6.1 目录

```text
collectors/geopolitical-source-monitor/
  geopolitical_source_monitor.py
  config.json
  README.md
  run.bat
  fixtures/
    source_samples.json
  output/
```

### 6.2 站点适配器

每个来源配置以下字段：

- `id`、`name_zh`、`publisher`、`tier`、`language`；
- `entry_urls`、`allowed_hosts`；
- `discovery_mode`：`rss`、`sitemap`、`listing`、`public_metadata` 或 `licensed_api`；
- `rate_limit_seconds`、`timeout_seconds`、`max_pages`；
- `content_policy`：`public_fulltext` 或 `metadata_only`；
- `topic_hints` 和来源特有关键词；
- 可选环境变量名称，不在配置文件中保存密钥。

适配器负责发现 URL、解析标题/摘要/时间/正文和记录访问状态；主题判定、维度映射、去重与输出由共享管线处理。

### 6.3 请求策略

- 使用明确标识项目名称和联系方式占位符的 User-Agent。
- 读取并遵守 `robots.txt`；禁止的路径不请求。
- 每个站点串行限速，站点之间有限并发。
- 支持 `ETag`、`Last-Modified` 和本地 URL 缓存，减少重复请求。
- 对 `429`、`502`、`503` 使用有限指数退避；对 `401`、`403`、验证码和登录墙不反复重试。
- HTTP 成功但正文为空、登录页或挑战页时不得计为采集成功。

### 6.4 数据流

```text
来源配置
  → URL 发现
  → 标题级主题初筛
  → 公开正文或元数据采集
  → 正文级准入复核
  → 主题与维度映射
  → URL、来源 ID、标题日期和内容指纹去重
  → 原始文件归档
  → geo.v6/1 输出
  → 现有快照导入与中文化管线
```

## 7. 输出与审计

每条记录至少保留：

- `id`、`origin_id`、`title`、`summary`、`link`；
- `source_id`、`publisher`、`tier`、`language`；
- `published`、`event_at`、`fetched_at`、`first_seen`；
- `topics`、`dimensions`、`nature`、`verification`；
- `discovery_method`、`matched_discovery_terms`、`matched_admission_terms`；
- `content_access`：全文、公开摘要、仅标题或授权接口；
- `raw_refs` 和可选 `aliases`。

每轮生成：

- `output/geo-v6.json`：累积去重后的正式输出；
- `output/_collection_report.json`：候选数、准入数、排除数、重复数和错误；
- `output/_source_status.json`：逐来源最后成功时间、访问状态、解析状态与失败原因；
- 按运行时间保存列表页、公开正文或接口原始响应，受限正文不归档。

## 8. 错误处理

- 单个来源失败时继续执行其他来源，最终退出状态区分“全部失败”“部分完成”和“成功”。
- 来源结构变化时报告 `parse_error`，不得返回零记录并冒充正常无新增。
- 付费墙或登录墙报告 `restricted_metadata_only`，不记为程序故障。
- 官方授权接口未配置密钥时报告 `not_configured`，公开页面降级链路仍可运行。
- 标题与正文语言检测异常时保留原文并进入后续中文化，不在采集器内虚构译文。

## 9. 测试与验收

### 9.1 离线测试

- 20 个来源配置均有唯一 ID 和允许域名。
- 美伊、俄乌的正例分别覆盖军事、外交、制裁、经济、伤亡和军费。
- 体育、文化、一般贸易和同名实体误命中被排除。
- 仅标题记录不会被标记为全文证据。
- 同源更新与跨站转载去重行为符合预期。
- 403、429、登录墙、空正文和页面结构变化有不同状态。

### 9.2 在线验收

- 注册表可列出并单独执行采集器。
- 至少一个美国官方源、一个伊朗官方源、一个俄罗斯官方源、一个中国官方源、一个欧盟官方源和一个媒体源能成功形成记录或明确报告正常无新增。
- 每条正式记录能从快照追溯至公开原始链接和归档。
- 采集成功后能够进入现有美伊或俄乌页面、问答和简报。
- 数据源页面能够区分访问失败、受限元数据、正常无新增和成功采集。

## 10. 明确不在本次范围内

- 台海主题及台海资料采集；
- 绕过验证码、付费墙、登录验证或反自动化挑战；
- 购买或开通 Reuters、AP、AFP、Factiva 等授权服务；
- 把官方声明自动提升为已核验事实；
- 自动计算冲突概率或综合风险分数；
- 调整前端主题导航、资产分析和简报模板以支持第三主题。
