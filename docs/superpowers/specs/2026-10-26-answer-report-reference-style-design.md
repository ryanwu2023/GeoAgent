# 本地问答 HTML 导出参考样式设计

## 目标

将本地模型问答的 HTML 导出改造成与《从开战到僵持：美伊局势演变报告》一致的深色研究报告视觉，同时保持导出过程确定、可追溯、安全，不再次调用模型，也不根据版式需要虚构指标、图表或结论。

## 采用方案

采用“参考样式外壳 + 现有回答忠实排版”。导出器继续使用已持久化回答中的 `summary.text`、`citations`、`gaps`、主题、筛选范围和时间字段。Markdown 正文仍由禁用原生 HTML 的解析器渲染，引用链接仍经过 HTTP(S) 白名单校验。

不采用以下方案：

- 不复制附件中的固定美伊内容、SVG 图或指标数字，因为不同问答无法保证存在对应数据。
- 不在导出时再次调用模型重写正文，避免导出结果和用户已看到的回答不一致。
- 不用通用浅色后台模板，因为用户已指定深色研究报告作为视觉基准。

## 信息结构

1. 顶部报告区：GeoAgent 标识、问答标题、报告说明、主题、维度、日期范围、数据截至和生成时间。
2. 核心结论：从回答首个“结论摘要/核心判断”章节提取内容；无法可靠提取时显示简短的报告口径说明，不删除正文。
3. 信息卡：引用材料数、明确缺口数、数据截至时间和报告范围。只展示已有字段，不生成推测数值。
4. 综合研判：完整呈现已校验的 Markdown 回答，保留章节、表格、列表、引用和强调。
5. 证据与信源：逐条列出来源、标题、发布与采集时间、内容要点、层级、核验状态及原始链接。
6. 口径、限制与缺口：使用警示样式展示回答中已记录的数据缺口和统一研究边界。
7. 页脚：说明导出未再次调用模型、报道计数不是概率、市场同步变化不构成因果证明。

## 视觉系统

- 背景：`#0b1118`
- 主面板：`#121b25`
- 次面板：`#16202c`
- 分隔线：`#233240`
- 主文字：`#e6edf3`
- 次文字：`#9fb0c0`
- 金色重点：`#c9a227`
- 风险提示：`#d4573f`
- 缓和/确认：`#3f9e6a`
- 信息蓝：`#4a90c2`

使用系统中文无衬线字体，最大正文宽度 1120px。版式采用单栏研究长文，不保留原导出页的粘性侧栏。章节标题使用金色左边线和自动章节序号；表格、信息卡、引用与限制区沿用附件的视觉语言。

## 自适应与打印

- 820px 以下信息卡改为两列，窄屏进一步改为单列。
- 宽表格允许横向滚动，证据表在移动端保持可读。
- 打印时切换为白底深色文字，保留章节结构并避免单条证据跨页断裂。
- 保留键盘焦点样式、足够的颜色对比度以及长链接换行。

## 异常处理

- 无总结正文：保持现有 409 行为。
- 无逐条引用：显示明确空状态，不伪造来源。
- 无缺口：显示“当前回答未单列其他数据缺口”。
- 不安全链接：不渲染为可点击链接。
- 标题或 Markdown 含 HTML：继续转义，禁止脚本执行。

## 验收

- 导出页视觉与参考附件的深色、金色、单栏报告风格一致。
- 完整答案不再显示“见上”或被摘要替代。
- 引用发布时间、采集时间、来源等级和核验状态完整保留。
- 原始回答、内部回答 ID、快照 ID及危险 HTML 不泄漏到报告。
- 现有导出接口、文件名和前端下载操作保持兼容。
- 后端报告测试、相关接口测试和前端构建通过。
