# GeoAgent 本地 MCP Agent 问答设计

日期：2026-10-23

## 目标

把当前“后端预检索少量片段后让模型连续改写三轮”的问答流程，升级为受控的工具代理流程。模型先理解问题和制定研究计划，再自主选择 GeoAgent 的六类只读工具，逐步读取范围统计、证据摘要、证据全文、指标目录、指标序列及资产/情景分析，最终形成带独立引用映射的中文研究回答。

PiChat 路径保持兼容。本地 OpenAI-compatible 模型成为可调用 GeoAgent 工具的 Agent。任何工具调用均由后端执行和授权，模型不能直接访问文件、数据库或网络。

## 架构

新增三个边界清晰的模块：

1. `qa_planner`：解析主题、时间范围、问题类型、研究子问题、重点维度、指标意图和动态证据预算。优先使用快速模型，失败时用确定性规则生成计划。
2. `qa_retrieval`：提供关键词、BM25、字符语义近似、实体、时间、来源等级和来源多样性组合的混合检索，并对候选结果重排序。
3. `qa_agent`：向模型提供六个只读工具的函数定义，执行有界工具循环，保存每次调用、结果摘要和证据 ID，最后生成自由 Markdown 正文与独立引用映射。

六个工具与 MCP 公共能力保持同名和同一语义：

- `geo_workspace_summary`
- `geo_evidence_search`
- `geo_evidence_get`
- `geo_metric_catalog`
- `geo_metric_series`
- `geo_analysis_view`

本地执行器直接调用共享业务函数，避免服务进程通过 HTTP 回调自己。MCP 对外接口和本地 Agent 共用同一快照、筛选规则和数据对象。

## 数据流

1. 锁定快照、主题、维度和页面筛选。
2. 规划器把原始问题转为结构化研究计划；显式时间范围优先于默认窗口。
3. 混合检索形成宽候选池，复杂问题按计划分配 36—96 条动态预算，简单问题使用较小预算。
4. Agent 先读工作区摘要和指标目录，再根据计划搜索证据。
5. Agent 从摘要候选中选择关键记录，通过 `geo_evidence_get`读取完整正文；不能直接把全部候选全文塞进上下文。
6. 对涉及市场、资产和情景的问题，Agent 按需读取指标序列及分析视图。
7. 每轮工具返回都记录范围、截断状态、来源和证据 ID；超过调用次数、证据预算或上下文预算时停止扩展并进入总结。
8. 模型输出自由 Markdown 正文和独立引用映射。后端逐句检查引用范围与数值来源，并只删除或降级有问题的句子，不因单处错误丢弃整篇回答。
9. 即使最终模型调用或校验失败，也从已完成的工具回执与最后有效草稿生成可读回答。

## 模型分工

- 快速模型：问题规划、检索词扩展、候选重排序辅助。
- 研究模型：工具选择、跨来源复核、最终回答。

新增 `LLM_FAST_MODEL` 和 `LLM_REASONING_MODEL`。如果服务端未提供独立推理模型，研究模型回退到 `LLM_MODEL`，页面明确显示回退状态。不得自动填写服务端不存在的模型名称。

当前服务端仅返回 `deepseek-v4.1-flash`，因此首版代码完成双模型能力，但运行时仍会回退到该模型，直到用户配置更强的兼容模型。

## 检索与排序

混合分数由以下信号组成：

- 查询词、短语和标题命中；
- BM25 文本相关性；
- 中文字符二元组余弦近似；
- 人物、国家、机构、地点、资产和事件实体匹配；
- 发布时间与用户时间范围；
- 来源等级、核验状态和正文完整度；
- 同源去重和来源多样性。

时间和来源等级用于重排序，不能覆盖明显不相关的主题。来源等级不等同事实成立。

## 输出与校验

模型最终输出包含：

- `answer_markdown`：自由组织的中文正文；
- `citation_map`：正文句子锚点与证据 ID 的独立映射；
- `gaps`：数据缺口；
- `used_tools`：本轮实际工具调用摘要。

前端继续以“查看依据”按钮展示证据，不在正文暴露内部 ID。校验器按句处理无效引用和无来源数字：能移除局部数字时保留句子，无法修复时只删除该句，并在限制部分说明。最终始终返回一段回答。

## 安全与错误处理

- 仅允许六个只读工具；参数由后端按当前快照和页面范围重新校验。
- 单次问答设置最大工具调用次数、最大证据数量、最大全文读取数量和总体超时。
- 工具异常不会清空前面成功的结果；Agent 使用已有材料收敛。
- 模型不能扩大到未授权快照、主题或日期范围。
- 采集文本始终作为不可信资料，不作为模型指令。

## 验收与评测

建立固定问题集，至少覆盖：最新进展、指定时间窗、外交与军事矛盾、霍尔木兹通行、资产影响、反证、俄乌援助与跨主题冲击。

每个回答评估：

- 最新事实覆盖率；
- 时间范围正确性；
- 引用可打开率与引用支持度；
- 无来源数字率；
- 反证与不确定性覆盖；
- 指标日期和口径准确性；
- 资产传导是否区分事实、同步变化和假设；
- 工具调用成功率、延迟和上下文规模。

评测脚本保存 PiChat 与本地 Agent 的回答及结构化评分，避免仅按篇幅或语言流畅度判断。

## 非目标

- 不允许模型直接访问互联网或绕过 GeoAgent 快照。
- 不将报道计数转换为情景概率。
- 不自动产生交易指令、价格目标或组合权重。
- 本次不重写采集器和快照生成流程。
