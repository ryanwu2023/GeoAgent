# 问答 HTML 业务核心判断设计

## 一、目标

优化智能问答导出的 HTML 报告，使首页“核心判断”成为直接回应用户问题的业务结论，而不是快照时间、检索范围、来源等级或证据数量的复述。

核心判断需要回答：

1. 当前局势或事项处于什么状态；
2. 最近发生了什么关键变化；
3. 后续走向主要取决于什么；
4. 对用户问题涉及的大类资产或研究决策意味着什么。

## 二、范围识别

核心判断不固定为美伊、俄乌两个主题，而是按照用户原始问题的业务语境确定范围。

- 用户只问美伊：聚焦美伊局势、关键依据、资产传导和触发条件。
- 用户只问俄乌：聚焦俄乌局势，不强行加入美伊内容。
- 用户问整体地缘局势、两个主题或跨主题资产影响：并列比较相关主题，说明共同驱动与差异。
- 用户问霍尔木兹、援乌、油价等细分问题：围绕该问题作答，只补充理解结论所需的上层局势和资产含义。

范围识别同时使用用户原始问题、回答主题与筛选条件、当前回答正文以及同一快照中的可用证据。模型不得无依据扩大到用户未询问且与结论无关的主题。

## 三、生成流程

用户点击“保存为 HTML 报告”后，后端执行以下流程：

1. 读取已经持久化的问答及其原始问题、主题、筛选条件、总结正文、引用和数据缺口；
2. 在同一不可变快照内补充与问题语境相关的主题摘要、关键事件和量化指标；
3. 调用当前已配置模型，单独生成一段 150 至 300 字的业务核心判断；
4. 对模型输出执行中文、长度、数字和引用范围校验；
5. 将通过校验的核心判断写入 HTML 首页；
6. 原问答正文、证据表和数据缺口保持原样，不因本次模型调用而重写。

导出模型调用只用于生成核心判断，不重新生成整份报告。

## 四、内容约束

核心判断必须：

- 首句直接给出状态或方向，例如“加速升级”“战术性停顿”“高压僵持”“缓和窗口扩大”；
- 使用最关键的可核验变化解释判断；
- 说明未来走势的主要触发条件；
- 在问题涉及资产或宏观影响时，给出有条件的资产含义；
- 区分已发生事实、媒体转述、当事方声明和研究推论。

核心判断不得：

- 以“截至某快照”“本轮检索”“证据窗口”“T2/T3 来源占比”开头；
- 把报道条数写成事件概率或冲突强度；
- 添加当前回答、同一快照证据和结构化指标中不存在的数字；
- 把华泰内部消息或单方声明写成已核实事实；
- 强制加入与用户问题无关的另一主题。

快照时间、检索范围、来源等级、证据数量和数据缺口统一保留在报告元数据及“口径、限制与缺口”部分。

## 五、提示词与输出协议

模型输入包括：

- 用户原始问题；
- 主题、维度和日期筛选；
- 当前问答总结；
- 当前回答实际引用的证据摘要；
- 同快照内与问题语境相关的关键主题摘要与量化指标；
- 已知数据缺口和证据边界。

模型输出采用独立结构：

```json
{
  "business_lead": "150至300字的中文业务核心判断",
  "evidence_ids": ["仅限输入中提供的证据ID"],
  "metric_series": ["仅限输入中提供的指标序列"],
  "scope": "usiran、ukraine、cross_topic或specific_issue"
}
```

HTML 不展示内部证据 ID；ID 只用于后端校验。

## 六、校验与回退

后端必须校验：

- `business_lead` 是完整中文段落；
- 字数在允许范围内；
- 引用 ID 属于本次允许范围；
- 新增数字可由引用证据或结构化指标支持；
- 内容范围与用户问题一致。

模型超时、服务不可用、JSON 无效或校验失败时，HTML 仍须成功导出。回退顺序为：

1. 从当前回答的“结论摘要”中提取首个具有方向、依据和触发条件的业务段落；
2. 若没有合格段落，使用当前已有的安全说明文案；
3. 在“口径、限制与缺口”中记录“业务核心判断生成失败，已使用原回答回退”，不在首页伪造新结论。

模型错误、密钥、服务地址和内部异常信息不得写入 HTML。

## 七、接口与持久化

现有下载入口保持不变：

`GET /api/answers/{answer_id}/report.html`

该接口改为异步模型生成流程。每次导出允许重新生成业务核心判断，因此结果可能随模型配置变化；原问答和快照保持不变。

首版不额外持久化业务核心判断。后续如需完全可复现，可增加导出报告版本表，保存模型、生成时间、核心判断和校验结果。

## 八、用户体验

- 点击导出后展示“正在生成业务核心判断并整理报告”；
- 导出按钮在请求期间禁用，避免重复调用；
- 沿用现有 HTML 深色研究报告样式；
- 首页只展示核心判断正文，不展示生成过程；
- 报告底部说明“导出时调用模型生成业务核心判断，原问答正文与引用未重新生成”。

## 九、验收标准

1. 美伊单主题问题的核心判断只聚焦美伊及相关资产含义；
2. 俄乌单主题问题不强行加入美伊；
3. 跨主题问题能够比较不同战场的状态、驱动和资产影响；
4. 细分问题的核心判断围绕原始问题，不泛化为整个平台介绍；
5. 首页核心判断不再以快照、检索范围、来源等级或证据数量开头；
6. 无来源数字无法进入核心判断；
7. 模型不可用或超时时仍能导出 HTML；
8. 原问答正文、引用、发布时间、采集时间和原始链接保持不变；
9. 导出过程中不泄露内部 ID、模型密钥、服务地址或异常堆栈；
10. 新增后端测试覆盖单主题、跨主题、细分问题、无效数字、模型超时和回退导出。
