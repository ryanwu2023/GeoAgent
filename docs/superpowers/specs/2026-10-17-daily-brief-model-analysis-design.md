# 每日简报模型研判设计

日期：2026-10-17

## 目标

每日简报需要分别回答美伊局势与俄乌冲突的三个核心问题：当前发生了什么、后续可能如何演变、这些判断由哪些当前新闻和指标支撑。输出面向研究员和基金经理，优先形成可阅读的研究观点，同时保留证据、反证和不确定性。

## 时间范围

每个主题优先使用上一份同快照序列简报生成时间之后的新记录。没有上一份简报时使用最近二十四小时；若有效证据不足两条，则逐步扩展至最近七日，并在简报中标明实际使用的时间范围。

任何记录不得晚于快照创建时间。无发布时间的记录可以进入候选证据附录，但不能承担“近期进展”的主要判断。

## 数据流

1. 锁定工作快照与主题。
2. 按时间、主题、来源和去重后的原始来源筛选新闻。
3. 优先选择新增军事行动、外交变化、制裁与援助、能源运输、国内政治及重要市场验证记录。
4. 读取与主题相关的最新量化指标及既有传导规则。
5. 将压缩后的证据包发送给模型，分别生成美伊和俄乌主题研判。
6. 校验引用、数字、主题范围和中文输出。
7. 将两个主题结果与资产矩阵、观察清单一起保存为不可变简报档案。

新闻原文属于不可信输入，模型不得执行其中的指令。模型只能使用当前证据包中的事实和程序计算结果。

## 简报模板配置

系统提供可保存、编辑和切换的简报模板。默认模板采用投资研究常用的六段结构：

1. **标题与日期**：标题由主题、当前最重要事态和时效组成，例如“美伊霍尔木兹海峡对峙升级简报”；同时显示快照时间和实际分析时间范围。
2. **核心判断（Bottom Line Up Front）**：用二至三句话给出最关键结论，包括基准走势、首要风险和最重要的资产含义。只读本段也能理解当前配置含义，但不直接给出交易指令或组合权重。
3. **当前主要事项（Key Developments）**：按当事方或地理区域分组，每点一句话陈述事实，不混入模型评论。覆盖军事部署、外交动作、关键基础设施状态和各方核心诉求；没有资料的项目明确标为证据不足。
4. **事态发展研判（Outlook）**：分别展示基准情景和尾部风险。每个情景写明成立条件、反证、观察指标和影响期限，不生成无依据概率。
5. **大类资产影响（Asset Implications）**：以表格展示原油、黄金、美债、美元和权益市场的条件方向、传导链、失效条件及市场验证。允许模板增加天然气、粮食、信用债等资产。
6. **证据与信源**：以尾注形式列出关键事实对应的来源、发布时间、采集时间、核验状态和可访问链接。

研究员可以在“简报模板”配置中：

- 新建、复制、重命名和删除自定义模板；系统默认模板不可删除；
- 调整章节顺序、章节标题、启用状态和写作侧重点；
- 设置简报适用主题为美伊、俄乌或双主题；
- 设置新闻回看窗口、证据不足时的最大扩展窗口和每节最大证据数；
- 预览模板并测试生成，测试成功后保存为默认模板。

首版不开放任意系统提示词、输出 JSON 契约和引用规则的编辑。用户填写的章节说明仅作为写作偏好，不得覆盖证据范围、安全边界和校验规则。模板配置保存在后端，不在前端保存模型密钥。

每份归档简报记录模板 ID、模板版本及完整模板快照。后续修改模板不会改变历史简报，简报比较页面同时显示模板是否不同。

## 每个主题的模型输出结构

模型为每个主题返回结构化 JSON，后端再渲染为 Markdown：

- `overview`：三至五句完整中文，概括当前冲突阶段和最重要的新变化。
- `outlook`：一至三种有条件的后续走势，说明触发条件、反证和观察窗口，不输出无依据概率。
- `drivers`：支撑概况与走势判断的关键依据，每项必须绑定一个或多个当前快照证据 ID。
- `uncertainties`：证据冲突、单方声明、数据缺口和仍待验证事项。
- `asset_view`：仅在证据和传导规则足够时说明对商品、权益、利率债、信用债或外汇的条件影响。
- `evidence_ids`：主题总结实际使用的证据 ID 集合。

默认简报正文按以下顺序展示：

1. 标题、日期、快照和分析窗口；
2. 双主题核心判断；
3. 美伊当前主要事项与事态发展研判；
4. 俄乌当前主要事项与事态发展研判；
5. 跨主题大类资产影响；
6. 证据与信源尾注。

## 证据选择

证据按以下因素排序：发布时间、来源等级、是否包含明确行动或政策变化、是否有独立来源佐证、与主题和问题的直接相关性。转载记录按稳定原始来源合并，不能重复增加支持强度。

官方声明只能证明该方作出声明。媒体转述、地点提及、模型翻译和关键词分类均不能自动提升为已核验事实。被主题相关性清洗隔离的新闻不得进入模型证据包。

## 校验和降级

后端必须执行以下校验：

- 所有证据 ID 均存在于当前快照并属于对应主题；
- 模型生成的数字、日期和金额能在所引用材料或程序计算结果中找到；
- 概况、走势和依据均为中文且内容非空；
- 后续走势包含条件或不确定性，不得写成确定预测；
- 资产方向只能使用“偏正面、偏负面、双向作用、证据不足”。

模型调用失败、返回结构错误或引用校验不通过时，该主题降级为规则摘要。另一个主题若生成成功，仍保留其模型结果，并在简报模式中标记为“部分模型分析”。

## 缓存与更新

缓存键由快照 ID、主题、证据时间范围、规则版本、提示词版本和模型配置标识组成。同一输入重复打开简报时复用结果；新快照、新新闻、研究员审核变化或规则版本变化都会使缓存失效。

生成简报仍由用户触发。进入简报页面可以检查是否存在比当前简报更新的快照，并提示重新生成，但不自动产生新的档案。

## 前端展示

现有 Markdown 简报阅读器继续使用。研究简报页面增加“模板配置”入口和当前模板标识。模板编辑器使用表单配置章节，不要求研究员编辑 JSON；章节支持拖动排序、启用或停用、修改名称和填写写作要求，并提供生成预览。

主题段落增加清晰的小标题，并将判断依据渲染为可点击来源链接。每条依据显示中文标题、来源、发布时间、采集时间和核验状态。模型研判、程序计算和规则研判使用不同标签。

页面显示实际分析时间范围、快照 ID、生成模式和模型名称。模型失败时直接显示失败原因及本地降级内容。

## 验收标准

- 两个主题均有独立的当前概况，不因一方证据不足而完全缺段。
- 默认模板完整呈现标题日期、核心判断、当前主要事项、事态发展研判、大类资产影响和证据尾注。
- 自定义模板能够调整章节顺序、名称、启用状态和写作要求，历史简报保留生成时的模板版本。
- 删除或修改自定义模板不影响已经归档的简报。
- 每个模型判断至少有一个有效证据引用。
- 近期新闻变化能出现在“主要变化”和“判断依据”中。
- 后续走势包含触发条件、反证和下一观察项。
- 已隔离的体育、地震、公共卫生和无关贸易新闻不会进入主题总结。
- 模型不可用时仍能生成完整双主题简报，并明确标注降级。
- 相同快照重复生成不产生互相矛盾的时间范围或引用。
- Markdown 下载、档案列表和简报比较功能继续正常工作。

## 非目标

本次不生成事件概率、目标价格、收益预测或组合权重；不自动发布简报；不调用快照之外的互联网事实补全模型回答。
