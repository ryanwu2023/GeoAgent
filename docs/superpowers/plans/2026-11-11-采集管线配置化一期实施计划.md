# 采集管线配置化（一期）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在页面上新增、编辑、停用、删除网页 / RSS 采集管线，按管线单独定时运行，运行结束在左侧列表展示“本次新增”。

**Architecture:** 管线配置存 PostgreSQL（当前态 + 只追加版本）。运行时把配置写成文件，作为一个临时注册表条目交给现有 `execute_once`，由新的 `collectors/pipeline-runner/pipeline_runner.py` 把管线配置翻译成多源采集器的配置格式后调用其 `run_collection`，产物 `pipeline-<id>/output/geo-v6.json` 走现有导入链路进快照。运行结束对比去重台账写入本次新增条目。进程内调度线程按 `next_run_at` 触发。

**Tech Stack:** Python 3 / FastAPI / psycopg 3 / PostgreSQL；React + TypeScript（Vite）；pytest（真实 PostgreSQL，`GEO_TEST_DATABASE_URL`）；`node --test`。

**Spec:** [docs/superpowers/specs/2026-11-11-采集管线自定义配置设计.md](../specs/2026-11-11-采集管线自定义配置设计.md)

## Global Constraints

- 一期范围 = 设计 §13 一期：表结构、service、REST、列表与编辑页、web/rss 引擎、试跑、按管线调度、本次新增展示。MCP 工具、search 源、多源采集器迁移不在本期。
- 所有新表包含六个公共字段：`created_by TEXT NULL`、`created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`、`updated_by TEXT NULL`、`updated_at TIMESTAMPTZ NULL`、`data_timestamp TIMESTAMPTZ NOT NULL`、`is_deleted BOOLEAN NOT NULL DEFAULT false`；每张表、每个字段写中文 `COMMENT`，同步 `docs/database/data-dictionary.md`。
- 主题可多选（2026-11-11 用户决定，Task 13），至少一个，只能取 `usiran`、`ukraine`（D3 中的“未归类”推迟到后续，导入链路目前拒绝未注册主题）。
- 不做单独定时（2026-11-11 用户决定，Task 14/15）：已启用的管线随现有整批采集运行并进入同一快照；新增管线默认未启用，管理员测试无误、确认后启用；“测试运行”不进快照、不写去重台账、不占整批锁。现有采集器默认全部列出且保持当前启用状态，builtin 启用状态以 `collector_config` 排除列表为唯一来源。
- 配置上限：来源 ≤ 30；锚词 + 强锚词 + 排除词合计 ≤ 200；`max_pages_per_source` ≤ 5；`link_include_pattern` ≤ 200 字符。
- URL 只允许 `http`/`https`，host 必须在该来源 `allowed_hosts` 内，且解析结果不得是私网、回环、链路本地、保留地址。
- 权限（D2，2026-11-11 用户决定）：管线页面与 `/api/pipelines*` 全部接口（含只读）仅管理员可用。网页登录启用时 `request.state.web_user` 在 htpasswd 管理员集合内为管理员，否则 403 “仅管理员可以管理采集管线”；未启用网页登录时操作者记为 `local` 且视为管理员。`owner` 只记录创建人（Task 12）。
- `GEO_COLLECTION_MODE=remote` 时所有写操作与运行返回 409 “远端采集模式下此操作需在采集端（Sealos）处理”（复用 `backend/app.py` 的 `_local_collection_only`），只读接口照常。
- 管线运行（含 builtin 单独调度）不导入快照：只写运行记录与本次新增，已发布输出在下一次整批导入时并入快照并回填 `snapshot_id`（Task 11，2026-11-11 用户决定）。
- HFT 内网不纳入本次变更；remote 模式 409 守卫保留，不再为内网做任何适配。
- 功能开关 `GEO_PIPELINES_ENABLED`（默认 `true`）；为 `false` 时调度线程不启动、`/api/pipelines*` 返回 404、前端不显示页签。
- 前端沿用现有 `prototype.css` 视觉与 StockLink v4.5 Token，不改其它页面。
- 所有用户可见文案为中文。

## Review Focus

1. **PiChat 或他人并发修改后页面仍在编辑旧版本**：保存时必须 409 并提示刷新，不得静默覆盖 → Task 4 `test_update_rejects_stale_version`、Task 9 前端 `conflictMessage`。
2. **RSS 返回 HTML 错误页 / 非 XML / 超大 body**：该来源记为 `failed`，管线 `partial`，不得抛出导致整条管线失败 → Task 2 `test_feed_parser_rejects_non_xml`。
3. **域名解析到内网（DNS 重绑定式）**：保存时 host 白名单通过但解析到 `10.x`，必须拒绝 → Task 3 `test_rejects_host_resolving_to_private_ip`。
4. **删除后重建同名管线**：允许，且旧管线的去重台账不影响新管线的“本次新增” → Task 4 `test_recreate_after_delete_has_fresh_seen`。
5. **服务重启时有运行中的管线**：运行记录不能永远停在 `running`，`next_run_at` 被重算 → Task 6 `test_recover_marks_interrupted_runs`。

  - `delete_pipeline(actor, pipeline_id) -> None`：逻辑删除并停用。
  - `rollback(actor, pipeline_id, *, to_version: int, expected_version: int) -> dict`：以旧版本 `config` 新建版本。
  - `list_versions(pipeline_id) -> list[dict]`
  - `can_edit(actor, pipeline) -> bool`：管理员或 `owner == actor.username`。
  - 所有写操作同一事务内 `SELECT … FOR UPDATE`，维护 `updated_by/updated_at`；`data_timestamp` 不随更新改变。
  - `kind="builtin"` 的管线只允许改 `enabled`、`interval_sec`、`daily_times`、`timezone`，其它字段抛 `BUILTIN_READONLY`。
