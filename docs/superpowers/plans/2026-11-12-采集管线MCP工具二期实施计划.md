# 采集管线 MCP 工具（二期）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 PiChat 经 GeoAgent MCP 查看、新建、修改、试跑、测试运行、启停、删除、回滚采集管线，并读取运行结果。

**Architecture:** 在 `backend/geo_mcp/` 新增 `pipeline_tools.py`，以 `register_pipeline_tools(server)` 注册 13 个 `geo_pipeline_*` 工具；工具体只做参数校验与结果投影，业务全部调用一期的 `backend/pipeline_service.py`、`backend/pipeline_runs.py`，走现有 `_run_tool`/审计/信封。

**Tech Stack:** Python 3 / FastMCP（`mcp` 包）/ PostgreSQL；pytest。

**Spec:** [docs/superpowers/specs/2026-11-11-采集管线自定义配置设计.md](../specs/2026-11-11-采集管线自定义配置设计.md) §8（2026-11-12 修订）

## Global Constraints

- 所有持有有效 GeoAgent MCP Key 的调用方都能看到并调用全部管线工具，不区分管理员；MCP 操作者记为 `Actor("mcp:<principal_id>", is_admin=True, channel="mcp")`，版本 `source_channel="mcp"`。
- 功能开关 `GEO_PIPELINES_ENABLED=false` → 管线工具返回错误码 `GEO_FEATURE_DISABLED`；`GEO_COLLECTION_MODE=remote` → 写入类工具返回 `GEO_REMOTE_READ_ONLY`（只读工具照常）。
- `PipelineError` 映射为 MCP 错误码：`NOT_FOUND→GEO_NOT_FOUND`、`VERSION_CONFLICT→GEO_VERSION_CONFLICT`（details 含 `current_version`）、`INVALID→GEO_INVALID_ARGUMENT`（details 含 `field`）、`BUILTIN_READONLY→GEO_INVALID_ARGUMENT`、`CONFLICT→GEO_CONFLICT`、`PREVIEW_FAILED→GEO_UPSTREAM_FAILED`、`FORBIDDEN→GEO_SCOPE_DENIED`；中文 message 原样透传。
- 只读工具 `readOnlyHint=True, destructiveHint=False`；写工具 `readOnlyHint=False`，删除与停用 `destructiveHint=True`。
- 返回值是投影：列表最多 50 条、运行条目每页最多 50 条、摘要截断 500 字；不返回源站正文与 `raw_files`。
- 工具说明（description）用中文，写清用途、关键参数与注意事项；`geo_pipeline_set_enabled` 说明必须写“启用前先向用户展示最近一次测试运行结果并取得明确同意”。
- 所有用户可见文案为中文。

## Review Focus

1. **PiChat 传错类型**（如 `topics` 传字符串、`expected_version` 传字符串数字）：返回 `GEO_INVALID_ARGUMENT` 与字段，不抛 500 → Task 2 `test_create_rejects_bad_types`。
2. **未带 expected_version 的更新**：拒绝 → Task 2 `test_update_requires_expected_version`。
3. **测试运行在 MCP 调用线程里同步跑数分钟导致超时**：`geo_pipeline_trial` 只启动后台线程立即返回 → Task 2 `test_trial_returns_immediately`。
4. **对内置采集器调用写入工具**：返回清楚的中文错误 → Task 2 `test_builtin_write_rejected`。
5. **dry_run 不落库**：版本号与数据库不变 → Task 2 `test_update_dry_run_no_write`。

### Task 1: 只读工具

**Files:**
- Create: `backend/geo_mcp/pipeline_tools.py`
- Modify: `backend/geo_mcp/server.py`（`create_server` 末尾调用 `register_pipeline_tools(server)`）
- Test: `tests/test_mcp_pipeline_tools.py`

**Interfaces:**
- Consumes: `pipeline_service.list_pipelines/get_pipeline/list_versions`、`pipeline_runs.list_runs/list_run_items`、`pipeline_scheduler.pipelines_enabled`、`server._run_tool`。
- Produces（参数 → 返回 data）：
  - `geo_pipeline_list(topic="", status="", kind="", q="", limit=50)` → `{"items":[{id,name,kind,topics,enabled,source_count,current_version,last_status,last_trigger,last_finished_at,last_new_items}],"total"}`
  - `geo_pipeline_get(pipeline_id)` → 行字段 + `config`
  - `geo_pipeline_versions(pipeline_id, limit=20)` → `[{version,created_at,created_by,change_note,source_channel,source_count,term_count}]`
  - `geo_pipeline_runs(pipeline_id, limit=10)` → `[{run_id,trigger,status,started_at,finished_at,snapshot_id,error,stats:{candidates,accepted,new_items,sources:{id:{state,error,candidates,accepted}}}}]`
  - `geo_pipeline_run_items(pipeline_id, run_id="", offset=0, limit=20)` → `{run_id,trigger,items:[{title,summary(≤500),source_id,source_type,published_at,matched_terms,dimensions,evidence_id}],total}`；`run_id` 为空取最近一次运行
  - `geo_pipeline_recent_results(hours=24)`（1–168）→ `[{pipeline_id,name,runs,new_items,last_trigger,last_finished_at}]`，按新增条数降序
- 共用 helper：`_actor(principal) -> Actor`、`_guard(write: bool)`（开关 / 远端检查）、`_raise(PipelineError)`（错误码映射）。

### Task 2: 写入工具与接入文档

**Files:**
- Modify: `backend/geo_mcp/pipeline_tools.py`
- Create: `docs/agent/geo-pipeline-mcp.md`（入口、鉴权、全部工具输入输出、错误码、限制、最小示例、推荐对话流程：新建→试跑→测试运行→展示结果→用户同意→启用）
- Test: `tests/test_mcp_pipeline_tools.py`

**Interfaces:**
- Produces：
  - `geo_pipeline_preview(row, config, limit=5)` → 试跑结果（不落库）
  - `geo_pipeline_create(row, config, change_note="", dry_run=False)` → 管线；`dry_run` 时只校验并返回规范化后的 `row`/`config`
  - `geo_pipeline_update(pipeline_id, expected_version, row_patch={}, config=None, change_note="", dry_run=False)` → 管线；`dry_run` 时返回 `{"current_version", "changes": {字段: [旧, 新]}}`，不写库
  - `geo_pipeline_trial(pipeline_id)` → `{"pipeline_id","accepted":true,"hint":"约 1–3 分钟后用 geo_pipeline_runs 查看"}`；后台线程执行 `pipeline_runs.run_trial`
  - `geo_pipeline_set_enabled(pipeline_id, enabled)` → 管线
  - `geo_pipeline_delete(pipeline_id)` → `{"deleted": true}`
  - `geo_pipeline_rollback(pipeline_id, to_version, expected_version)` → 管线
