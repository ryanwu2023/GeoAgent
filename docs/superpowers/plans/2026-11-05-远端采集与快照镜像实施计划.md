# 远端采集与快照镜像实施计划

**Goal:** HFT 内网 GeoAgent 以 `remote` 模式通过 MCP 让 Sealos 采集，实时显示进度，并把同一份快照与译文镜像回内网。

**Architecture:** Sealos 新增 `geo_collect_request` 与 `geo_mirror_manifest/chunk`，复用 `geo_collector_status`；HFT 新增 `backend/remote_collection.py`（MCP 客户端封装、快照拉取、远端任务镜像、定期同步），采集路由按 `GEO_COLLECTION_MODE` 分支。

**Spec:** `docs/superpowers/specs/2026-11-05-远端采集与快照镜像设计.md`

**Tech Stack:** Python 3.12、FastAPI、FastMCP、httpx、PostgreSQL、pytest、React/TypeScript。

## Global Constraints

- 默认 `local` 模式行为与现有代码完全一致；`geo-sync/v1` 输出字节不变。
- 不新增数据库表或列；远端运行进度复用 `collection-runs` 报告目录与现有账本表。
- Key 不进入日志、报告、页面或镜像。
- 每个任务先写失败测试，再实现，再跑相关测试。
- 工作区有与本功能无关的未提交修改（`deploy/README.md` TLS 段、`deploy/sealos-custom-domain.yaml`、`sites/`），提交时只暂存本计划文件。
