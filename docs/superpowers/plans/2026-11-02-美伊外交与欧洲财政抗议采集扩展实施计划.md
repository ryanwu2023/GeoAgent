# 美伊外交与欧洲财政抗议采集扩展实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 扩展现有采集器，使其稳定采集美伊提案交换、军事筹划与补给动作，以及法德公共开支抗议，并保持事实与分析推论分离。

**Architecture:** 继续使用现有采集器的配置驱动分类，不新增重复爬虫。专用采集器负责主题发现和结构化标签，`geopolitical-source-monitor`负责T1/T2回源，统一适配器保留 buckets、flags 和来源信息供快照、问答与简报使用。

**Tech Stack:** Python 3、JSON配置、pytest、现有 records-jsonl / geo-v6 适配流程。

**Spec:** `docs/superpowers/specs/2026-11-02-美伊外交与欧洲财政抗议采集扩展设计.md`

## Global Constraints

- 所有新增文档、标签和用户可见说明使用中文。
- 不新增采集器；复用 `diplomacy-monitor`、`readiness-monitor`、`israel-monitor`、`eu-domestic-monitor` 和 `geopolitical-source-monitor`。
- 采集事实、声明和程序标签，不把模型推论写成已验证事实。
- “两日方案”与“雷扎伊尚未正式回复”必须作为不同事件保存。
- 一般抗议不得自动映射为援乌能力下降。
- 保持现有 records-jsonl、去重、历史归档和适配器接口兼容。
- 工作区存在用户未提交修改；每个提交仅包含本计划明确列出的文件。

## Review Focus

- 只有人物名或“信件”而无美伊提案动作的文章应被排除；由任务1反例测试覆盖。
- “已审阅来信”不能被标成“已正式回复”；由任务1状态拆分测试覆盖。
- 运输机或拦截弹报道不能自动推断打击已经批准；由任务2性质标签测试覆盖。
- 体育、治安个案及无财政诉求的一般游行不能进入欧盟财政压力桶；由任务3反例测试覆盖。
- 公共开支抗议只有明确涉及军费、征兵、援乌或预算取舍时才产生援乌能力候选标记；由任务3 flags测试覆盖。
