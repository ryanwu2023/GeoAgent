# 启动和停止项目

在项目根目录双击：

- `start.bat`：后台启动服务，打开 http://127.0.0.1:8000/ 。已启动时不会重复创建进程。
- `stop.bat`：关闭由启动脚本登记的本项目服务，不会关闭其他 Python 程序或独立爬虫任务，不删除数据。

也可以在 PowerShell 中运行：

```powershell
.\start.ps1
.\start.ps1 -NoBrowser
.\start.ps1 -Build
.\stop.ps1
```

`-Build` 在服务停止时重新编译前端；一般修改代码后先停止，再使用该参数启动。首次运行没有前端产物时会自动构建。Python 依赖缺失会提示安装命令，不自动改动系统 Python 环境。

日志：根目录 `server.stdout.log` 和 `server.stderr.log`。
进程登记：`data/server-process.json`，不要手工修改。

停止前同时核对进程编号、创建时间和本项目启动文件路径，避免 PID 被复用时误停其他程序。若端口被其他或未登记服务占用，启动脚本会说明并停止，不自动抢占端口。

若单位策略禁止运行 PowerShell 脚本，按单位要求处理；脚本不会修改系统执行策略。
