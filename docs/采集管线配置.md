# 采集管线配置使用说明（一期）

本页面只给管理员使用，用来**添加采集源**（网页、RSS），不另起一套调度。新增的管线在你确认启用后，随现有整批采集一起运行，结果进入同一份快照。

## 1. 入口与权限

- 导航“采集管线配置”页签仅管理员可见；非管理员不显示页签，接口返回 403。
- 功能由环境变量 `GEO_PIPELINES_ENABLED` 控制，关闭时页签隐藏，整批采集也不再追加配置化管线。
- 远端模式（只读镜像）下页面只能查看，不能新建、修改、启用或运行。
- 本期只支持网页和 RSS 来源；search 来源和 PiChat/MCP 操作管线属于后续阶段。

## 2. 新建管线与添加来源

点“新建管线”，填名称、说明，选择一个或多个主题，再添加来源。

| 字段 | 说明 |
| --- | --- |
| 来源 ID、名称 | ID 在管线内唯一；名称用于展示 |
| RSS 订阅地址 | 填入后会自动带出允许域名，可手工调整 |
| 网页入口页 | 每行一个；可再填“链接匹配正则”（≤200 字符）限制要抓的文章链接 |
| 允许的域名 | 抓取的所有链接必须落在这些域名内，域名用小写主机名，不含协议、路径、端口；内网和保留地址一律拒绝 |
| 来源等级 | T1 权威 / T2 主流 / T3 补充，影响证据展示的可信度标记 |
| 正文策略 | “仅元数据”只保存标题、摘要等；“公开全文”适用于允许公开读取全文的来源 |
| 每个来源最多翻页 | 整条管线的请求上限，防止过度抓取 |

保存时校验不通过会给出中文原因（如主机不在白名单、地址指向内网）。新建的管线默认**未启用**。

## 3. 关键词含义

在“关键词”页签配置过滤规则：

- **锚词**：条目标题或摘要至少命中一个，才可能入选。
- **强锚词**：命中即视为强相关，可单独支撑入选。
- **排除词**：命中则直接排除。
- **不要求命中事项词**：勾选后，只需命中锚词即可入选；不勾选时还需同时命中主题的事项准入词。

注意：英文按**整词**匹配，大小写不敏感。`Israel` 不会命中 `Israeli`，`strike` 不会命中 `strikes`。需要多种词形时请分别添加，例如同时写 `Israel` 和 `Israeli`。中文按子串匹配。

## 4. 多主题与条目归属

一条管线可选多个主题（如美伊、俄乌）。条目归入哪个主题，按所选主题的内置锚词判断：命中哪个主题的锚词就归入哪个。**如果所选主题的内置锚词都没有命中，该条目会同时归入所有所选主题**，可能出现与某主题关系不大的条目被多个主题展示。建议主题差异大时拆成多条管线，或把关键词写具体。

## 5. 试跑、测试运行与整批运行

| 方式 | 触发 | 写数据 | 进快照 | 占整批锁 | 用途 |
| --- | --- | --- | --- | --- | --- |
| 试跑 | 编辑页点“试跑” | 否 | 否 | 否 | 看每个来源的候选、入选/未入选及原因、命中词，调关键词 |
| 测试运行 | 管线详情点“测试运行”（仅配置化管线） | 产物写入测试目录；记入运行记录和“本次新增”，标“测试结果，不进快照” | 否 | 否，只锁该管线自身，整批进行中也可运行 | 用真实抓取流程验证效果 |
| 整批运行 | 现有整批采集（每 6 小时全量或手动整批）自动带上所有已启用管线 | 是 | 是，与其他采集器同一次导入 | 是（即整批本身） | 正式产出 |

测试运行里看过的条目，正式整批运行时仍然算“新增”。内置采集器不支持试跑和测试运行（接口返回 422）。

## 6. 启用与停用

- 点列表中的启用开关，会弹出“确认启用”窗口，展示启用后的影响和最近一次测试运行结果。**确认即代表同意**该管线从下一次整批采集起运行并进入快照。
- 建议先试跑、再测试运行，确认结果合理后再启用。
- **停用或删除**会让该管线的输出目录被移到退役目录，后续快照不再包含它；已进入历史快照的数据保持不变。删除为逻辑删除，名称可被重新使用。

## 7. 内置采集器

列表中同时显示现有内置采集器（带“内置”标签）。开关等同于采集监控页的“排除采集器”：关闭即写入排除列表，不再随整批运行。内置采集器的配置不能在此页修改。

## 8. 本次新增

运行完成后，该行显示“新增 N 条”。打开“本次新增”页签可看到标题、摘要、来源、北京时间发布时间、命中词和中文研究维度；打开后标记消失（已读状态仅存在你的浏览器本地）。测试运行的条目标“测试结果，不进快照”；整批运行的条目在快照生成后可跳转到证据详情，未并入前标“待并入快照”。

## 9. 版本历史与回滚

每次保存都生成新版本并保留完整历史。“版本历史”页签可查看各版本差异。回滚到旧版本会**生成新版本**（内容等同旧版本），下一次运行使用该配置。

## 10. 多人同时编辑

保存时带版本号校验。若别人已先保存，你会收到版本冲突提示（409），需刷新后在最新版本上重新修改。

## 11. 本地使用注意

项目写入保护默认只放行 8000、8010、8011、5173 端口的页面来源。在其他本地端口访问时，保存和运行会被拒绝，需设置 `GEOAGENT_ALLOWED_ORIGINS`，例如 `GEOAGENT_ALLOWED_ORIGINS=http://localhost:8131`。

## 12. 已知限制（一期）

- 勾选“不要求命中事项词”后，未入选条目的原因文案仍可能显示“未同时命中主题锚点与事项准入词”（实际是未命中锚词）。
- 英文词形不做归一，见第 3 节。
- 多主题回退归属规则见第 4 节。
- 内网（HFT）部署不在本次变更范围。
