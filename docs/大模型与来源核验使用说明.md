# 模型配置与来源核验

## 填写模型

项目根目录已提供 `.env`，填写下列两项并保存即可；程序每次请求读取，不需要重启。

```dotenv
LLM_BASE_URL=https://你的服务地址/v1
LLM_API_KEY=你的密钥
LLM_MODEL=
LLM_TIMEOUT=45
```

接口协议为兼容 OpenAI Chat Completions。URL 可填基础路径（例如包含 `/v1`）或完整 `/chat/completions` 地址。不要填网页聊天地址。不支持只提供 Responses 或 Anthropic Messages 协议的地址。

模型名称留空时请求同一服务的 `/models`，选返回的首个非嵌入、语音、图像模型；自动发现不保证该模型具有对话权限。若服务不支持模型列表、自动发现的模型不能对话或希望指定模型，请补填 `LLM_MODEL`。

进入“数据源 → 模型连接 → 测试模型连接”。测试发送一条固定连接确认消息，不发送研究资料。研究问答会向所配置服务发送当前范围检索出的资料和计算结果；重新翻译会发送选中记录的原文。密钥仅后端读取，不存入浏览器，也不写入对话或错误日志。

问答保留本地计算、快照、引用和模型标识；失败时显示连接、权限、额度或输出校验问题，并保留本地证据。连续追问会使用同一快照、主题、维度和日期条件下上一问题作为检索上下文，不把上一回答自动当作事实证据。

## 翻译

证据详情同时提供中文摘要、质量提示和可展开的完整原文。术语统一仅修正常见人名、地点与机构译名，不改变原始档案。

本地翻译不再把所有阿拉伯字母视为波斯语，也不再将明显的西里尔字母、希伯来语或未知语言送入英中模型。不能可靠处理时显示缺口，不伪装为已翻译。

配置模型后可点击“使用已配置模型重新翻译”。输出须通过结构、非空、数字表达和混合语言检查才替换缓存；失败时保留旧译文。数字格式换写也可能触发复核，属于保守检查。

自动检查无法证明否定、主体、条件、因果和语气都译对。所有机器译文仍需语义核验，不能承诺无偏差。

## 链接与引用

`scripts/audit_links.py` 对快照内不同 HTTP(S) 链接逐条发起 GET，保存检查时间、HTTP 状态、最终地址、页面标题或失败原因；同一链接只检查一次。记录位于 `data/link-audits/`。链接不含数据上传参数，不绕过验证码或访问权限。

证据详情显示检查结果。访问成功只能说明页面可访问，不代表正文与摘要相符或事实可信。聚合新闻入口尤其可能仍需回到出版方原文。

简报只有在已有来源索引或候选来源列表能匹配记录 ID 时才生成“来源编号”链接；没有索引的 ID 保持原样，不拼接或猜测外部来源。原始 Markdown 和历史快照保持不变。

## 执行与记录

- `python scripts/refresh_crawlers.py`：一轮自检、采集、独立对账，逐项目日志在 `data/collection-runs/`。没有对账脚本时标记 `not_provided`。
- `python scripts/audit_links.py`：对最新快照逐链接检查，可断点续跑。
- `python scripts/audit_translations.py`：生成逐条机械翻译质量检查 CSV，不等同人工语义复核。
