## 产品判断
逐指标独立爬虫的路线可行，但应统一数据契约、调度、健康监控与质量门禁。当前更适合做资料聚合、指标变化监测和可追溯研究，不宜把关键词统计包装为局势概率。
研究员的主要价值是减少搜集与核对工作；基金经理需要结论、作用条件、反证和下一触发点。接下来的重点应从增加新闻数量转向补充事件执行和经济暴露数据。
## 当前边界
所有有输出的项目按当前格式接入；.workbuddy 与 tools 为辅助目录，不当作新闻源。备份文件、重复的日期日报及原始网页抓取缓存不重复计入检索；用于归一化的数据及最新附属材料随快照归档。金融历史保留在指标序列及累计观测档案，不能把同一观测多次采集计为多次变化。
新增同格式项目会在手动更新快照时被发现；这不等同于已配置自动采集调度。归档日报可以打开阅读，但未将其重复作为新闻全文索引。
