# 数据补充与情景判断清单

本轮接入：美国高收益债及投资级债期权调整利差、十年期盈亏平衡通胀率、欧元兑美元。与已有原油、黄金、美债、股指、库存和航道数据一起进入快照、指标、资产分析及简报。新增序列使用 FRED 官方 CSV，保留来源和采集时间；不是实时行情。

## 优先级一：把新闻变成可比较的事件

每条军事或外交事件至少保存：发生时间、报道时间、行动方、地点及定位精度、行动类型、强度口径、来源、独立来源分组、核验状态。修订与撤回保留版本。同一新闻的转载不能变成多次行动。

| 主题 | 最优先增加 | 用途 |
|---|---|---|
| 美伊 | 设施实际损失、停产量、出口量、运输中断与恢复时间 | 区分威胁声明与持续供应冲击 |
| 美伊 | 海运费、战争险、替代航线及可用产能 | 连接事件与能源、通胀、企业成本 |
| 美伊 | 协议文本、执行日期、违反协议事件、第三方核查 | 判断缓和是否已落实 |
| 俄乌 | 按统一口径的战线与远程打击记录 | 判断地域或强度是否扩大 |
| 俄乌 | 援助承诺、拨款、实际交付分别记录 | 判断支持能力，不把宣布金额视为已交付 |
| 俄乌 | 欧洲天然气、储气与进口、粮食出口和运输 | 补齐地区与商品暴露，不能用美国天然气替代欧洲价格 |

## 优先级二：完善资产验证

权益补地区股指、行业相对收益及盈利修正；利率债补政策预期、发行供给和期限溢价；信用债补发行人暴露及再融资；外汇补双边利差及资金流。中国市场另补主要股指、人民币国债曲线及行业暴露。目前美股、美债数据不能代表全部市场。

先按事件发生时间与市场交易时区对齐，再定义观察窗口和对照资产；同时记录央行、经济数据等其他冲击。单次同步涨跌只记为观察，不宣称因果。

## 民调的最低结构

调查机构、调查起止日期、样本量、目标人群、调查方式、完整问题、选项及比例、误差范围、原始发布链接。同一机构同一问题才优先连接趋势；跨机构比较保留方法差异。当前新闻中的百分比包含误提取，不作为可比指标自动发布。

## 情景的判断方式

持续消耗：行动连续、实际补给仍在、未形成可验证停火。升级扩散：相对前期行动地域、强度或参与方扩大且得到独立核实。缓和收束：协议有执行证据，行动下降或运输恢复，而不仅是谈判表态。

每次判断写清观察窗口、前期基准、支持证据、反证与失效条件。现阶段页面列出成立条件及待补清单，不把报道数量变成概率，也不自动宣布某情景成立。

## 刷新方式

执行 `python scripts/supplement_market.py` 后，在页面点击“更新快照”。当前未设置定时运行。已冻结的快照不回写新行情；历史研究如需严格当时可得数据，还需各序列的历史发布版本，不能使用今天下载的修订值冒充当时已知值。
