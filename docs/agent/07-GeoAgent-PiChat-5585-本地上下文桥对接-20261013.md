## 临时本地配置与恢复

当前本地启动方式（8010前端/8011 BFF及MCP）：

```sh
GEOAGENT_LOCAL_PICHAT_ORIGIN=http://127.0.0.1:5585 .venv/bin/python scripts/start_local.py
```

`backend.integrations.settings()`同时控制前端公开origin与BFF身份目标。此覆盖只允许回环地址，**不会复用原配置App Key**，只读取独立`GEOAGENT_LOCAL_PICHAT_APP_KEY`；缺该Key时BFF在发出请求前返回503。原DB配置/原环境不改，覆盖开启时保存PiChat配置返回409，防止覆盖原凭证。

恢复：停止上述GeoAgent进程，去掉两个`GEOAGENT_LOCAL_PICHAT_*`变量，以`.venv/bin/python scripts/start_local.py`启动，即重新读取原持久配置。不启动/停止9172，不修改生产或Office配置。不要输出Key或放入浏览器URL。
