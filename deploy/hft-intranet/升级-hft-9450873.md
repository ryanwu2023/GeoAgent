# 内网升级到 geoagent:hft-9450873（用户管理 + PiChat 同步）

新版本：管理员（账号文件里的账号）可在页面创建、改密、删除普通用户，普通用户同步为 PiChat 嵌入用户，右侧问答按人区分。升级只换镜像，`/etc/geoagent/geoagent.env`（含 Sealos 远端采集 Key）、账号文件、数据和数据库保持不变；`web_users` 表在启动时自动创建。

## 上传（JumpServer 批量传输到 172.16.91.120，落在 /tmp）

- `geoagent-hft-9450873.tar.gz` 及 `.sha256`
- `upgrade-geoagent.sh`
- `migrate-file-users.sh`

## 1. 换镜像

```bash
cd /tmp && sha256sum -c geoagent-hft-9450873.tar.gz.sha256
sudo IMG_REF=geoagent:hft-9450873 bash /tmp/upgrade-geoagent.sh /tmp/geoagent-hft-9450873.tar.gz
```

脚本会备份 `/etc/containers/systemd/geoagent.container`、等待 `/readyz` 就绪并打印回滚命令。

## 2. 把原有个人账号改为普通用户

升级后账号文件里的所有账号都是管理员。liying、wangjinxiang、zhouxuejun、liuhao、lizhi 应改为普通用户：

```bash
sudo bash /tmp/migrate-file-users.sh liying wangjinxiang zhouxuejun liuhao lizhi
```

- 提示输入 admin 的密码；脚本先备份账号文件（`auth.bak-<时间>`）。
- 逐个从账号文件移除并经页面同一接口创建为普通用户，密码仍等于账号名，用户无感；同时在 PiChat（172.16.91.119）创建对应嵌入用户。
- 某个账号创建失败（如 PiChat 不可达）会自动恢复为文件账号并在最后列出，修复后对它单独重跑即可。
- 前提：页面“连接配置”里的 PiChat 地址与应用 Key 可用（右侧问答能正常打开即可）。

## 3. 验证

- admin 登录，页头出现“用户管理”，列表里 5 个普通用户都有 PiChat 用户 ID。
- 任一普通用户登录：看不到“用户管理”，右侧问答可用。

## 回滚

按升级脚本打印的命令把 `Image=` 改回 `geoagent:hft-b96be18` 并重启；如已迁移账号，再用备份恢复账号文件：

```bash
sudo cp -p /data/geoagent/auth/auth.bak-<时间> /data/geoagent/auth/auth
```

旧版本不读取 `web_users` 表，表保留无影响；PiChat 中已建的嵌入用户保留。
